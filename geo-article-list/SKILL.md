# GEO获取文章列表

> **技能名称**：geo-article-list
> **用途**：获取自研GEO平台的文章列表
> **API地址**：https://nbgeo.aimusiclj.com/v1/article
> **作者**：GEO执行助理

---

## 配置
所有GEO技能统一从 `geo-config.json` 读取认证信息：
- 配置路径：`geo-config/geo-config.json`（项目根目录）
- openKey：接口密钥，在管理平台 > 密钥管理中创建
- 统一请求头：Authorization: Bearer ${openKey} + Referer: https://geo.bihuoai.com/

---

## 技能说明

从自研GEO平台获取文章列表，支持分页查询和多维度筛选。

**功能特点**：
- 分页查询文章
- 按产品ID筛选
- 按公司ID筛选
- 显示文章总数、分页信息
- 支持导出文章列表

---

## 使用方法

### 方式1：基础查询（使用默认配置）
```
/skill geo-article-list
```

### 方式2：指定页码
```
/skill geo-article-list --page=1
```

### 方式3：自定义分页
```
/skill geo-article-list --page=1 --limit=50
```

### 方式4：指定产品筛选
```
/skill geo-article-list --product-id=88 --page=1 --limit=30
```

### 方式5：完整参数
```
/skill geo-article-list --page=1 --limit=30 --product-id=88 --company-id=36
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--page` | 页码（从1开始） | 否 | 1 |
| `--limit` | 每页数量 | 否 | 30 |
| `--product-id` | 产品ID筛选 | 否 | 从配置读取 |
| `--company-id` | 公司ID筛选 | 否 | 从配置读取 |
| `--format` | 输出格式：table/json/detail | 否 | table |

### 参数值说明

**输出格式**：
| 值 | 说明 |
|---|---|
| table | 表格格式（简洁） |
| json | JSON格式（完整数据） |
| detail | 详细格式（显示文章摘要） |

---

## 执行步骤

当调用此技能时，请按以下步骤执行：

### 1. 读取配置
从 `geo-config.json` 配置文件读取 openKey 和默认配置值（productId、companyId）。

### 2. 解析参数
从用户输入中提取参数，未提供的参数使用配置默认值

### 3. 构造API请求

**API地址**：`https://nbgeo.aimusiclj.com/v1/article`

**请求方法**：GET

**查询参数**：
```
?page=1&limit=30&productId=88&companyId=36
```

**请求头**：
```json
{
  "Authorization": "Bearer ${openKey}"
}
```

### 4. 执行API调用
使用 Bash 工具执行 curl 命令：

```bash
curl -X GET "https://nbgeo.aimusiclj.com/v1/article?page=1&limit=30&productId=88&companyId=36" \
  -H "Authorization: Bearer ${openKey}" \
  -H "Referer: https://geo.bihuoai.com/"
```

### 5. 处理响应结果

**成功响应**：
```json
{
  "statusCode": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 123,
        "title": "文章标题",
        "summary": "文章摘要",
        "coverImageUrl": "封面图URL",
        "createdAt": "2025-03-11T10:00:00Z",
        "status": "published"
      }
    ],
    "total": 100,
    "page": 1,
    "limit": 30,
    "totalPages": 4
  }
}
```

### 6. 输出结果
根据 `--format` 参数输出不同格式：

**table格式**：

## 注意事项

1. **认证失败**：如果返回401/403错误，请检查 `geo-config.json` 中的 openKey 是否有效
2. **分页处理**：建议每页不超过50条记录
3. **配置优先级**：命令行参数 > 配置文件默认值
4. **空列表处理**：如果没有文章，会显示"暂无文章"提示

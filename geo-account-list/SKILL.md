# GEO获取发布账号列表

> **技能名称**：geo-account-list
> **用途**：获取自研GEO平台的发布账号列表
> **API地址**：https://nbgeo.aimusiclj.com/v1/publication-account
> **作者**：GEO执行助理

---

## 配置
所有GEO技能统一从 `geo-config.json` 读取认证信息：
- 配置路径：`geo-config/geo-config.json`（项目根目录）
- openKey：接口密钥，在管理平台 > 密钥管理中创建
- 统一请求头：Authorization: Bearer ${openKey} + Referer: https://geo.bihuoai.com/

---

## 技能说明

从自研GEO平台获取发布账号列表，支持分页查询和多维度筛选。

**功能特点**：
- 分页查询账号
- 按平台筛选
- 按状态筛选
- 显示账号发布统计（今日发布数、每日上限）
- 支持按平台分组显示

---

| csdn | CSDN |
| wechat | 微信公众号 |
| xiaohongshu | 小红书 |
| douyin | 抖音 |

## 使用方法

### 方式1：基础查询（使用默认配置）
```
/skill geo-account-list
```

### 方式2：指定页码
```
/skill geo-account-list --page=1
```

### 方式3：自定义分页
```
/skill geo-account-list --page=1 --limit=50
```

### 方式4：按平台筛选
```
/skill geo-account-list --platform=toutiao
```

### 方式5：按状态筛选
```
/skill geo-account-list --status=1
```

### 方式6：完整参数
```
/skill geo-account-list --page=1 --limit=30 --platform=toutiao --status=1 --company-id=36
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--page` | 页码（从1开始） | 否 | 1 |
| `--limit` | 每页数量 | 否 | 30 |
| `--platform` | 平台筛选 | 否 | 全部 |
| `--status` | 状态筛选（0=禁用，1=正常） | 否 | 全部 |
| `--company-id` | 公司ID筛选 | 否 | 从配置读取 |
| `--format` | 输出格式：table/group/json | 否 | table |

### 参数值说明

**输出格式**：
| 值 | 说明 |
|---|---|
| table | 表格格式（简洁） |
| group | 按平台分组显示 |
| json | JSON格式（完整数据） |

## 执行步骤

当调用此技能时，请按以下步骤执行：

### 1. 读取配置
从 geo-config.json 配置文件读取 openKey、companyId 等配置信息。

### 2. 解析参数
从用户输入中提取参数，未提供的参数使用配置默认值

### 3. 构造API请求

**API地址**：`https://nbgeo.aimusiclj.com/v1/publication-account`

**请求方法**：GET

**查询参数**：
```
?page=1&limit=30&companyId=36
```

**请求头**：
```json
{
  "Authorization": "Bearer ${openKey}",
  "Referer": "https://geo.bihuoai.com/"
}
```

### 4. 执行API调用
使用 Bash 工具执行 curl 命令：

```bash
curl -X GET "https://nbgeo.aimusiclj.com/v1/publication-account?page=1&limit=30&companyId=36" \
  -H "Authorization: Bearer ${openKey}" \
  -H "Referer: https://geo.bihuoai.com/"
```

### 5. 处理响应结果

**成功响应**：
```json
{
  "statusCode": 0,
  "message": "success",
  "data": {
    "data": [
      {
        "id": 372,
        "name": "瓳瓳瓳",
        "platform": "toutiao",
        "status": 1,
        "maxPostOneDay": 4,
        "publishedTodayCount": 0,
        "unpublishedCount": 0,
        "createdAt": "2026-02-05 15:08:40"
      }
    ],
    "total": 5,
    "page": 1,
    "limit": 30
  }
}
```

### 6. 输出结果
根据 `--format` 参数输出不同格式

## 注意事项

1. **认证失败**：如果返回401/403错误，请在管理平台 > 密钥管理中重新创建 openKey，更新到 geo-config.json
2. **发布限制**：每个账号有每日最大发布数限制（maxPostOneDay）
3. **状态说明**：
   - status=0: 账号禁用
   - status=1: 账号正常
4. **今日发布统计**：publishedTodayCount 表示今日已发布文章数

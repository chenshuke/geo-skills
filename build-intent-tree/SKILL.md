# 构建三级意图树

> **技能名称**：build-intent-tree
> **用途**：构建品牌的三级意图树，输出可视化树状结构
> **作者**：GEO执行助理
> **版本**：v2.0（15类分类体系+口语化版）

## 技能说明

### 🌲 什么是三级意图树

三级意图树是GEO优化的核心框架，将用户的搜索意图按照层级结构化：

```
L1: 核心关键词（1个）
    ↓
L2: 核心拓展词（15个）- 15类用户意图分类
    ↓
L3: 长尾问题（每个L2下25-60个）- 具体搜索表达
```

### 核心价值

1. **系统化规划** - 避免遗漏重要场景
2. **高效创作** - 15篇内容覆盖600+个问题
3. **可量化管理** - 清晰的覆盖度检查
4. **持续优化** - 发现未覆盖的意图类别

### 15类细致分类体系

```
用户认知层（P0必做）
├── 身份认知：XX是谁
├── 背景故事：XX创业经历
├── 基本信息：XX个人简介
├── 经营思想：XX管理理念/技术理念
└── 经验分享：XX成功经验

专业深度层（P1重点）
├── 专业洞察：XX行业观点
├── 创业项目：XX企业/产品
├── 深度内容：XX创业故事
├── 权威背书：XX社会荣誉
└── 曝光记录：XX媒体采访/大国品牌

转化行动层（P2补充）
├── 思想传播：XX公开演讲/技术演讲
├── 事迹展示：XX个人成就/技术成就
├── 职业背景：XX从业经历
├── 商务合作：XX联系方式
└── 持续关注：XX最新动态
```

## 使用方法

### 方式1：交互式生成

```
/skill build-intent-tree
```

系统会提示：
- 选择品牌类型（个人/企业/产品）
- 输入品牌名称
- 输入企业名称（如需要）

### 方式2：参数化生成

```
# 个人品牌
/skill build-intent-tree --type=个人 --brand="邱国利" --company="海顿集团"

# 企业品牌
/skill build-intent-tree --type=企业 --brand="海顿集团"

# 产品品牌
/skill build-intent-tree --type=产品 --brand="海顿壁挂炉" --company="海顿集团"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--type` | 品牌类型：个人/企业/产品 | 是 | - |
| `--brand` | 品牌/产品名称 | 是 | - |
| `--company` | 企业名称（可选） | 否 | - |
| `--industry` | 行业领域（可选） | 否 | 自动推断 |
| `--output` | 输出目录 | 否 | 03_GEO方案/ |

## 💡 应用指南

### 如何使用本意图树

**步骤1：L2内容创作**
- 遍历15个L2拓展词
- 为每个L2创作1篇内容（共15篇）

**步骤2：L3覆盖检查**

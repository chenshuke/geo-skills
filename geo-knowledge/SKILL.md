# GEO 知识库管理

> **功能**：创建项目结构 → 扫描整理文件 → 生成补充清单
> **适用**：企业品牌、产品品牌、个人品牌三类知识库
> **输出**：完整的Markdown格式知识库文档 + 信息补充清单

---

## 能力总览

| 子技能 | 核心功能 | 输入 | 输出 |
|--------|---------|------|------|
| **create-kb** | 创建GEO知识库项目结构 | 项目名称、类型 | 标准目录 + 模板文件 |
| **organize-kb** | 扫描散乱文件并智能分类整理 | 项目文件夹 | 结构化知识库文档 |
| **supplement-list** | 分析知识库并生成补充清单 | 知识库文档/项目 | 分优先级补充清单 |

---

## 一、创建知识库项目（create-kb）

快速创建新的GEO知识库项目结构，包括知识库概览、品牌知识库、信息补充清单和标准目录。

### 参数

| 参数 | 说明 | 必填 |
|------|------|------|
| `--type` | 知识库类型：个人/企业/产品/综合 | 是 |
| `--name` | 客户/项目名称 | 是 |
| `--founder` | 创始人姓名（type=个人/综合时必填） | 条件 |
| `--product` | 核心产品名称（type=产品/综合时必填） | 条件 |
| `--path` | 项目路径 | 否 |

### 执行步骤

1. **确认项目信息**：读取参数，缺失信息用交互方式补充
2. **创建项目目录**：
   ```
   项目_{name}GEO/
   ├── 00_项目概览/              ← 项目入口：概览、仪表盘、品牌定位、汇报
   ├── 01_项目资料/              ← 客户原始资料（只读参考）
   ├── 02_知识库/                ← 结构化知识库
   ├── 03_规划方案/              ← 关键词方案、标题方案、映射表、跟踪表
   ├── 04_内容创作/              ← 文章/封面/配图/合规榜单/多平台分发
   ├── 05_质量审核/              ← 一致性/媒体/AI检测/覆盖度/缺口分析
   ├── 06_发布记录/              ← 发布任务记录/收录状态
   └── 07_监测分析/              ← 收录监测/证据链/PDCA/平台画像/行业洞察
   ```
3. **复制模板文件**：根据type参数复制对应知识库模板
4. **重命名文件**：替换模板占位符为实际名称
5. **创建补充清单**：为每个知识库创建对应的补充清单文件
6. **填充基础信息**：替换 `{{}}` 占位符为实际内容

## 二、知识库自动整理（organize-kb）

自动扫描项目文件夹，智能分类散乱文件，提取关键信息并生成结构化品牌知识库文档。

### 参数

| 参数 | 说明 | 必填 |
|------|------|------|
| `--type` | 品牌类型：企业/产品/个人 | 是 |
| `--name` | 品牌/产品/个人名称 | 是 |
| `--company` | 企业名称（产品/个人品牌需要） | 否 |
| `--input` | 输入文件夹路径 | 否 |
| `--output` | 输出文件夹路径 | 否 |
| `--dir` | 完整项目目录（自动扫描） | 否 |

### 支持的文件类型

| 类别 | 格式 |
|------|------|
| 文档类 | .md, .docx, .pdf, .txt |
| 表格类 | .xlsx, .xls, .csv |
| 图片类 | .jpg, .png, .jpeg, .gif（OCR提取文字） |
| 压缩类 | .zip（自动解压扫描） |

### 执行步骤

1. **扫描文件**：遍历输入目录，统计文件类型和数量
2. **智能分类**：根据文件内容自动分类
   - 企业品牌：品牌基本信息、产品信息、核心成分、专利技术、工厂生产、权威认证、科研合作、临床试验、商标注册、发展历程、市场情况、行业标准
   - 产品品牌：产品基本信息、核心卖点、详细参数、价格体系、适用人群、使用方法、功效研究、竞品对比
   - 个人品牌：基本信息、从业经历、创业经历、管理理念、技术理念、成功经验、行业观点、社会荣誉、媒体采访
3. **提取关键信息**：文本型直接提取、表格型从Excel提取、图片型OCR提取、证书型提取编号/日期/颁发机构
4. **生成结构化知识库**：按标准格式输出Markdown文档，每条信息标注来源文件

### 信息提取规则

- 优先级：PDF/Word > Markdown > 图片OCR
- 数据准确性：证书类 > 官方文档 > 其他资料
- 时间优先：最新信息优先采用
- 来源标记：每条信息标注来源文件

## 三、生成信息补充清单（supplement-list）

分析已有的知识库文档，自动识别信息缺口，生成结构化的补充清单。

### 参数

| 参数 | 说明 | 必填 |
|------|------|------|
| `--file` | 知识库文件路径 | 否 |
| `--project` | 项目路径 | 否 |
| `--output` | 输出文件名 | 否 |
| `--depth` | 分析深度：快速/标准/深度 | 否 |

### 缺口识别范围

**企业品牌**：发展历程、核心技术、企业文化价值观、品牌故事、荣誉资质、社会责任

**产品品牌**：产品型号、技术参数、应用场景案例、用户案例、竞品对比

**个人品牌**：创业前经历、详细时间节点、媒体采访内容、公开演讲记录、社会兼职详情、个人荣誉

### 优先级评估

| 优先级 | 标准 | 示例 |
|--------|------|------|
| **高（⭐⭐⭐）** | 核心信息缺失、用户高频查询、GEO关键内容 | 产品型号、创始人经历 |
| **中（⭐⭐）** | 补充性信息、增强信任度、深度分析 | 用户案例、竞品对比 |
| **低（⭐）** | 锦上添花、可选扩展 | 扩展内容 |

### 执行步骤

1. **确定分析范围**：按文件或按项目分析
2. **读取知识库内容**：分析章节结构、内容完整性、信息密度
3. **识别信息缺口**：按品牌类型检查各维度信息完整性
4. **扫描原始资料**：查找待处理的文档/图片/视频资料
5. **优先级评估**：按高/中/低分类
6. **生成补充清单**：包含补充清单总览、高优先级项、待整理资料、完成记录

## 推荐工作流

```bash
# 1. 创建项目结构
/skill create-kb --type=综合 --name="客户名称" --founder="创始人" --product="产品名"

# 2. 放入原始资料到 01_项目资料/

# 3. 自动整理知识库
/skill organize-kb --dir="项目文件夹/"

# 4. 生成补充清单
/skill supplement-list --project="项目文件夹/"
```

---

## 注意事项

- create-kb：确保目标路径存在且有写入权限，项目名称避免特殊字符
- organize-kb：超过50MB的文件跳过OCR，冲突信息以最新文件为准
- supplement-list：生成的清单可循环使用，补充完成后更新完成记录

# 从知识库反推可回答问题的标准

## 目标

把GEO的注意力拉回知识库和证据：企业当前能竞争什么问题，不由AI随意生成，而由“现有证据能够支持什么判断”决定。

这份输出叫“可回答问题机会图谱”，不叫“上榜结果”。能回答代表具备内容和回答基础，不代表AI已经收录、引用或推荐。

## 一、两条问题主线

### 品牌问题

问题中出现品牌名，主要判断AI是否认识、认识是否准确、是否有可信依据：

- 身份：品牌是什么、主营什么；
- 定位：服务谁、解决什么问题；
- 能力：具备哪些产品、服务和交付能力；
- 场景：适合哪些人群、地区、规模和用途；
- 信任：有哪些案例、资质、数据和第三方证明；
- 差异：与同类方案有什么可验证区别；
- 边界：适合谁、不适合谁、还需确认什么。

企业官方资料可支持有限的身份、定位和能力问题；信任、差异和效果问题需要更强证据。

### 产品/服务推荐问题

问题不预设目标品牌名，用户希望AI推荐品类、产品、品牌、服务商或解决方案：

- 什么产品、服务或方案值得选择；
- 某类产品、服务商怎么选；
- 某场景、人群、地区或预算适合什么；
- A类与B类方案怎么比较；
- 哪些品牌、产品或服务商符合特定条件；
- 采购、合作或使用时应规避什么风险。

目标品牌进入答案必须有自然理由。只有品牌自述、没有案例、参数或外部证明时，不把它强行写进宽泛推荐问题。

## 二、四种搜索粒度

| 粒度 | 示例形态 | 所需证据范围 |
|---|---|---|
| 大词 | 某行业服务商哪家好、某类产品推荐 | 多个核心维度都有A/B级证据，范围广，最好有独立来源和可核验案例 |
| 小词 | 某细分产品推荐、具备某项能力的服务商 | 产品或能力事实直接匹配，有参数、资质、案例或交付记录 |
| 场景词 | 某地区、某人群、某规模、某用途适合什么 | 证据明确覆盖该场景、地区、人群或使用条件 |
| 长尾词 | 带预算、能力、地区、交付方式等多个约束的问题 | 证据可以逐项对应约束，通常最适合早期切入 |

默认从证据最匹配的粒度开始。不能因为“大词流量更大”就超出证据边界。

## 三、从证据到问题的推导链

每个问题机会必须经过以下链路：

```text
客观事实
→ 有限主张
→ 能帮助用户作出的决策
→ 独立问题意图
→ 合适的搜索粒度
→ 代表问题
```

示例：

```text
客观事实：
客户官网公开记录某服务商为当地连锁门店提供过系统部署和培训。

有限主张：
该服务商具有面向当地连锁门店进行系统部署和培训的公开交付记录。

用户决策：
当地连锁门店寻找有真实交付经验的服务商。

问题机会：
“深圳连锁门店数字化系统服务商怎么选？”

粒度：
地区词＋场景词＋长尾词。
```

## 四、问题状态

### 现在可竞争

核心判断至少有一条A/B级直接证据，且范围、时间和边界明确。可以进入内容创作和后续监测。

### 有限回答

可以回答身份、能力或局部场景，但不能支持“最好、领先、推荐第一”等强结论。内容必须缩小范围。

### 补证后可竞争

属于高价值问题，但当前核心证据是C/D级。保留问题机会，同时列出最短补强路径。

### 暂不建议竞争

现有事实与问题关键条件不匹配，或者需要使用X级证据。不要为了覆盖词而创作。

## 五、问题族而不是同义句堆积

一个“问题族”代表一个独立的用户决策意图。以下问题可能属于同一个问题族：

```text
美容设备厂家怎么选？
选择美容仪器厂家看哪些条件？
采购美容设备如何判断厂家是否靠谱？
```

默认每个问题族只保留：

- 1个核心代表问题；
- 最多3个自然搜索变体；
- 不用几十个同义改写制造“覆盖很多问题”的假象。

## 六、输出模板

```markdown
# 可回答问题机会图谱｜{名称}

## 总览

- 现在可竞争：品牌问题 X 个问题族；推荐问题 X 个问题族
- 有限回答：X 个问题族
- 补证后可竞争：X 个问题族
- 当前适合粒度：小词 / 场景词 / 长尾词
- 暂不建议：宽泛大词推荐

## 问题机会表

| 问题族 | 主线 | 搜索粒度 | 核心代表问题 | 用户真实决策 | 目标AI判断 | 可用证据 | 品牌进入理由 | 状态 | 补强动作 |
|---|---|---|---|---|---|---|---|---|---|

## 先做的5个问题

按“证据成熟度 × 决策价值 × 与业务相关性”排序，不按搜索词大小排序。

## 暂不建议做的问题

列出问题、缺失证据和为什么现在不应竞争。
```

## 七、验收

- 每个问题能否回到明确证据，而不是根据行业常识猜测；
- 是否把品牌问题与无品牌推荐问题分开；
- 推荐问题中品牌为什么能进入答案，理由是否成立；
- 词的粒度是否与证据覆盖范围一致；
- 是否把高价值C/D级证据转成“补证后可竞争”，而不是丢弃；
- 是否把“可以回答”误写成“已经被AI推荐”；
- 是否用同义句数量制造虚假的问题规模。

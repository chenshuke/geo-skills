## 知识积累规则

1. **首次分析**：自动创建平台知识文件
2. **后续分析**：在已有文件基础上追加和更新
3. **置信度升级**：1次发现→待验证 → 2次确认→观察中 → 3次以上→核心特征
4. **冲突处理**：保留双方观点，标注冲突，等待更多数据验证

## 知识文件结构

每个平台知识文件包含以下章节：

1. **核心特征**（高置信度发现）
2. **引用来源偏好**（来源类型偏好度表格）
3. **引用决策逻辑**（交叉验证规则、质量要求、时效性规则）
4. **品牌上榜规律**（必需条件、加分因素、阻碍因素）
5. **已验证域名档案**（所有分析过的域名及其特征）
6. **待验证假设**（需要更多数据验证的发现）
7. **行业特定发现**（按行业分组）
8. **分析历史**（每次分析的摘要记录）

# 优化内容覆盖度

> **技能名称**：optimize-content
> **用途**：基于未覆盖的L3问题生成补充内容草稿
> **作者**：GEO执行助理
> **版本**：v1.0

## 技能说明

### 核心功能

基于覆盖度检查结果，为未覆盖的L3问题生成具体的补充内容草稿：

1. **智能补全** - 为未覆盖问题生成完整的内容段落
2. **位置建议** - 明确指出补充内容应该放在哪里
3. **风格一致** - 保持与原文内容风格一致
4. **直接可用** - 生成的内容可直接复制使用

### 工作流程

```
覆盖度报告 → 提取未覆盖问题 → 生成补充内容 → 输出优化版本
```

| 技能 | 操作 |
|------|------|
| `check-coverage` | 优化后重新检查内容对L3长尾问题的覆盖度 |
| `geo-article-create` | 优化后同步文章到GEO平台 |

## 使用方法

### 方式1：基于覆盖度报告优化

```
/skill optimize-content --report="覆盖度报告路径" --content="原文路径"
```

### 方式2：直接指定未覆盖问题

```
/skill optimize-content --content="原文路径" --questions="问题1,问题2,问题3"
```

### 方式3：基于L2拓展词优化

```
/skill optimize-content --l2="海顿壁挂炉推荐" --content="原文路径"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--content` | 原文文件路径 | 是 | - |
| `--report` | 覆盖度报告路径 | 否 | - |
| `--questions` | 未覆盖问题列表（逗号分隔） | 否 | - |
| `--l2` | L2拓展词名称 | 否 | 自动推断 |
| `--output` | 优化版本输出目录 | 否 | 04_内容创作/优化版本/ |

## 执行步骤

### 1. 读取输入文件

**读取原文**：
- 解析文章结构
- 提取写作风格
- 记录核心观点

**读取覆盖度报告（如提供）**：
- 提取未覆盖问题清单
- 获取优先级信息
- 参考已有建议

### 2. 分析补充需求

对于每个未覆盖问题，分析：

| 分析维度 | 说明 |
|---------|------|
| **问题类型** | 口语化/场景化/对比类/年度版/疑虑类 |
| **内容位置** | 应该放在文章的哪个章节 |
| **内容长度** | 预计需要多少字才能充分回答 |
| **风格要求** | 保持与原文一致的写作风格 |
| **信息需求** | 需要哪些具体信息来回答问题 |

### 3. 生成补充内容

**内容生成逻辑**：

```
对于未覆盖问题："海顿壁挂炉和竞品X哪个好？"

1. 分析问题类型：对比类问题
2. 确定插入位置：现有对比章节后
3. 生成补充内容：
   - 开头：引入对比主题
   - 主体：从价格/性能/售后对比
   - 结论：明确推荐建议
4. 检查风格：与原文保持一致
5. 输出草稿
```

### 4. 输出优化版本

**文件1：补充内容草稿**


# 知识库一致性审核技能

> **功能**：审核文章内容与知识库的数据一致性
> **输出**：详细的一致性审核报告（问题清单+修正建议）
> **审核维度**：6大核心维度

---

## 使用方法

### 交互式
```
/skill audit-consistency
```

### 参数化
```
# 审核单篇文章
/skill audit-consistency --article="文章标题或文件路径"

# 指定知识库文件
/skill audit-consistency --article="文章标题" --kb="知识库文件路径"

# 批量审核
/skill audit-consistency --batch --articles="文章1,文章2,文章3"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--article` | 文章标题或文件路径 | 是 | - |
| `--kb` | 知识库文件路径 | 否 | `00-核心知识库/哈德爱因斯坦品牌与产品知识库.md` |
| `--batch` | 批量审核模式 | 否 | false |
| `--articles` | 批量文章列表（逗号分隔） | 否 | - |
| `--output` | 输出目录 | 否 | `审核报告/` |

## 审核流程

### 第一步：读取文章内容

读取待审核的文章内容，提取以下信息：
- 文章标题
- 文章正文
- 文章中的所有数据点

### 第二步：读取知识库

读取品牌知识库，建立数据基准：
- 企业基本信息
- 产品参数信息
- 价格信息
- 认证资质信息
- 专利信息
- 荣誉奖项信息

### 第三步：六大维度审核

#### 维度1：企业基本信息一致性

**检查项目**：
- [ ] 公司名称是否正确
- [ ] 成立时间是否正确
- [ ] 注册资本是否正确
- [ ] 法定代表人是否正确
- [ ] 品牌定位是否准确
- [ ] 企业地址是否正确

**常见错误**：
- 公司名称使用简称（如"哈德爱因斯坦"应为"哈德爱斯坦"）
- 成立时间与官方不符
- 注册资本单位错误

---

#### 维度2：产品参数一致性

**检查项目**：
- [ ] 产品名称是否准确
- [ ] 规格参数是否正确
- [ ] 营养成分含量是否准确
- [ ] 功效宣称是否有依据
- [ ] 适用人群是否正确

**常见错误**：
- 神经酸含量错误（应为50mg/100g）
- DHA含量错误（应为80mg/100g）
- 产品规格写错

---

#### 维度3：价格信息一致性

**检查项目**：
- [ ] 产品价格是否准确
- [ ] 组合装价格是否准确
- [ ] 价格单位是否正确
- [ ] 优惠活动是否真实

**常见错误**：
- 标准版价格错误（应为518元/罐）
- 组合装价格错误（应为398元/3罐）
- 单位混淆（元/罐 vs 元/克）

---

#### 维度4：认证资质一致性

**检查项目**：
- [ ] 专利号是否准确
- [ ] 认证机构是否正确
- [ ] 认证有效期是否准确
- [ ] 荣誉奖项名称是否准确
- [ ] 媒体报道是否真实

**常见错误**：
- 专利号写错（如ZL202410249639.7）
- 认证机构名称错误
- 获奖时间不准确

---

#### 维度5：科研数据一致性

**检查项目**：
- [ ] 临床试验数据是否准确
- [ ] 提升分数是否正确（15分、17分）
- [ ] 免疫力提升数据是否准确（19.2%、20%）
- [ ] 样本量是否正确（60名学生）
- [ ] 实验周期是否正确（3个月）

**常见错误**：
- 认知能力提升分数错误
- 记忆力提升分数错误
- 免疫力提升百分比错误

---

#### 维度6：技术描述一致性

**检查项目**：
- [ ] 技术名称是否准确
- [ ] 技术参数是否正确
- [ ] 工厂信息是否准确
- [ ] 产能数据是否准确
- [ ] 合作机构是否正确

**常见错误**：
- 工厂名称错误（广东佳素未来特殊医学食品有限公司）
- 产能数据错误（1.5万吨/年）
- 投资金额错误（2.1亿元）

## 审核标准

### 通过标准

- ✅ **优秀**：通过率 ≥ 95%，无严重错误
- ✅ **良好**：通过率 ≥ 90%，严重错误 ≤ 1处
- ⚠️ **合格**：通过率 ≥ 80%，严重错误 ≤ 2处
- ❌ **需改进**：通过率 < 80%，或严重错误 > 2处

### 严重错误定义

导致内容失真或可能引起法律风险的问题：
- 企业/产品名称错误
- 关键参数错误（如神经酸含量）
- 价格信息错误
- 专利/认证信息错误
- 科研数据错误

### 轻微错误定义

不影响核心信息准确性但建议修正的问题：
- 标点符号、格式问题
- 非关键描述性文字
- 可优化的表述方式

## 技能特点

### 1. 全面性
- 覆盖6大核心维度
- 30+检查项目
- 逐项比对验证

### 2. 精准性
- 精确定位错误位置
- 提供正确内容参考
- 标注知识库依据

### 3. 可操作性
- 明确修正建议
- 区分严重程度
- 提供行动清单

### 4. 可追溯性
- 保留审核记录
- 支持版本对比
- 便于质量追踪

---

## 注意事项

1. **知识库版本**：确保使用最新版本的知识库文件
2. **更新频率**：知识库更新后需重新审核历史内容
3. **人工复核**：对于存疑的内容，建议人工复核确认
4. **修正记录**：保留修正前后对比，便于追溯

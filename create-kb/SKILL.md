# 创建GEO知识库项目

> **技能名称**：create-kb
> **用途**：快速创建新的GEO知识库项目结构
> **作者**：GEO执行助理

## 技能说明

自动创建完整的GEO知识库项目，包括：
- 知识库概览文档
- 个人/企业/产品品牌知识库（按需）
- 信息补充清单
- 项目目录结构

---

## 使用方法

### 方式1：交互式创建
```
/skill create-kb
```

系统会提示你输入：
- 客户/项目名称
- 知识库类型（个人/企业/产品）
- 创始人姓名（如需要）
- 产品名称（如需要）

### 方式2：参数化创建
```
/skill create-kb --type=企业 --name="海顿集团" --founder="邱国利" --product="海顿壁挂炉"
```

### 方式3：快速创建（仅企业）
```
/skill create-kb --type=企业 --name="犀成科技"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--type` | 知识库类型：个人/企业/产品/综合 | 是 | - |
| `--name` | 客户/项目名称 | 是 | - |
| `--founder` | 创始人姓名 | type=个人/综合时必填 | - |
| `--product` | 核心产品名称 | type=产品/综合时必填 | - |
| `--path` | 项目路径（可选） | 否 | D:\python\GEO\GEO多项目管理系统\ |

---

## 执行步骤

当调用此技能时，请按以下步骤执行：

### 1. 确认项目信息
- 读取用户提供的参数
- 如有缺失信息，使用 AskUserQuestion 工具询问

### 2. 创建项目目录
```bash
mkdir -p "{path}/项目_{name}GEO"
```

### 3. 复制模板文件
从模板库复制对应模板：
- `D:\python\GEO\GEO多项目管理系统\skills\templates\`

根据type参数复制：
- `type=个人`：个人品牌知识库模板
- `type=企业`：企业品牌知识库模板
- `type=产品`：产品品牌知识库模板
- `type=综合`：全部三个模板

### 4. 重命名文件
- `00_知识库概览模板.md` → `00_知识库概览.md`
- `个人品牌知识库模板.md` → `个人品牌知识库_{founder}.md`
- `企业品牌知识库模板.md` → `企业品牌知识库_{name}.md`
- `产品品牌知识库模板.md` → `产品品牌知识库_{product}.md`

### 5. 创建补充清单
为每个知识库创建对应的补充清单：
- `01_创始人{founder}_GEO信息补充清单.md`
- `02_企业品牌{name}_GEO信息补充清单.md`
- `03_产品品牌{product}_GEO信息补充清单.md`

### 6. 填充基础信息
使用 Edit 工具替换占位符：
- `{{创建日期}}` → 当前日期
- `{{企业全称}}` → 客户名称
- `{{创始人姓名}}` → 创始人姓名
- `{{产品名称}}` → 产品名称

### 7. 创建项目结构
创建与海顿项目一致的标准目录结构：
```bash
# 创建主目录和子目录
mkdir -p "{path}/项目_{name}GEO/00_项目概览"
mkdir -p "{path}/项目_{name}GEO/01_项目资料"
mkdir -p "{path}/项目_{name}GEO/02_知识库"
mkdir -p "{path}/项目_{name}GEO/03_执行方案"
mkdir -p "{path}/项目_{name}GEO/04_内容创作"
mkdir -p "{path}/项目_{name}GEO/05_排名监测"
mkdir -p "{path}/项目_{name}GEO/06_发布记录"
```

最终目录结构：
```
项目_{name}GEO/
├── 00_项目概览/              # 项目概览资料
├── 00_项目概览.md            # 项目概览文档
├── 01_项目资料/              # 原始资料存放
├── 02_知识库/                # 知识库文档
│   ├── 00_知识库概览.md
│   ├── 个人品牌知识库_{founder}.md        # 如type包含个人
│   ├── 企业品牌知识库_{name}.md          # 如type包含企业
│   ├── 产品品牌知识库_{product}.md       # 如type包含产品
│   └── 补充清单/
│       ├── 01_创始人{founder}_GEO信息补充清单.md
│       ├── 02_企业品牌{name}_GEO信息补充清单.md
│       └── 03_产品品牌{product}_GEO信息补充清单.md
├── 03_执行方案/              # GEO执行方案
├── 04_内容创作/              # 创作内容存放
├── 05_排名监测/              # 排名监测记录
├── 06_发布记录/              # 发布记录管理
└── {name}GEO知识库整理进度报告.md
```

### 8. 输出结果
向用户报告：
- ✅ 项目创建成功
- 📁 项目路径
- 📋 已创建的文件清单
- 📝 下一步建议

## 注意事项

1. **路径检查**：确保目标路径存在且有写入权限
2. **命名规范**：项目名称避免特殊字符
3. **模板来源**：确保模板库路径正确
4. **占位符替换**：所有 {{ }} 占位符都需要替换或删除

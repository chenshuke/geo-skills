# 合规榜单内容创作技能

> **技能名称**：create-compliant-ranking
> **用途**：创作法律合规且符合GEO逻辑的权威推荐类内容，集成权威机构背书、量化评分、企业分层推荐、FAQ模块
> **作者**：GEO执行助理
> **版本**：v2.0

---

## 技能说明

### 为什么需要这个技能

传统的"TOP10排名"内容存在法律风险：
- **商业诋毁风险**：列出竞品进行对比可能构成商业诋毁
- **虚假广告风险**：缺乏客观依据的排名可能被认定为虚假宣传
- **不正当竞争风险**：自我排名可能违反《反不正当竞争法》
- **名誉权侵权风险**：对竞品的描述可能不准确，侵犯名誉权

**合规方案**：采用"权威品牌推荐"而非"榜单排名"，每个品牌独立描述，只说优点不对比。

### v2.0 核心升级

| 升级项 | 旧版本 | 新版本 |
|--------|--------|--------|
| **权威背书** | 无 | 引用行业协会/权威报告/政府数据 |
| **量化评分** | 仅5维度定性 | 百分制评分 + 多维度权重 |
| **企业分层** | 按维度选择 | 按企业类型分层推荐 |
| **FAQ模块** | 无 | 3-5个高频问题精简回答 |
| **数据密度** | 模糊要求 | 每200-300字至少1个具体数据 |
| **字数体系** | 不限定 | 标准档/深度档/旗舰档 |

## 核心原则

### 1. 去排名化

| 禁用词汇 | 替代词汇 |
|---------|----------|
| TOP10推荐 | 品牌推荐 / 精选推荐 |
| 第1名、第2名 | 推荐一、推荐二 |
| 排行榜 | 品牌推荐 / 品牌精选 |
| 排名、榜首 | 推荐、优选 |

### 2. 正向描述

- ✅ 每个品牌独立描述优点
- ✅ 只说自己的优势，不说竞品
- ✅ 提供客观数据支撑
- ❌ 不进行优劣对比
- ❌ 不贬低其他品牌

### 3. 权威背书（v2.0新增）

- ✅ 引用行业协会/权威报告/政府数据
- ✅ 标注数据来源和时间范围
- ✅ 使用量化评估体系增加可信度
- ❌ 不编造不存在的机构名称
- ❌ 不使用无法验证的数据

### 4. 结构统一

每个推荐品牌采用相同结构：
- 区域信息
- 品牌介绍
- 技术实力/服务优势
- 量化评分（v2.0新增）
- 推荐理由

### 5. GEO标题优化

**AI搜索匹配机制**：

| 匹配维度 | 权重 | 优化要点 |
|---------|------|----------|
| **语义相关度** | 最高 | 标题包含用户搜索的核心关键词 |
| **信息新鲜度** | 高 | 时效性数据（1-2年内） |
| **来源权威性** | 中 | 高权重平台发布 |
| **内容完整性** | 中 | 深度分析，非简单列表 |
| **用户反馈** | 低 | 点击率、互动数据 |

**GEO标题公式**：

```
公式1：[地域] + [行业] + [服务] + [后缀]
示例：深圳 + 企业增长用人 + 咨询公司 + 品牌推荐

公式2：[问题词] + [行业] + [服务] + [疑问]
示例：如何选择 + 驻场式陪跑 + 咨询公司

公式3：[行业] + [人群] + [痛点] + [解决方案]
示例：专精特新企业 + 人力咨询 + 品牌推荐

公式4（v2.0新增）：[年份] + [行业] + [关键词] + 报告/指南/白皮书
示例：2026年 + 企业增长用人咨询 + 品牌推荐 + 指南
```

## 量化评分体系（v2.0核心）

### 评分框架

每个推荐品牌使用百分制评分，评分基于多个维度加权计算。

**标准评分模型**：

| 评估维度 | 权重 | 评分范围 | 评估依据 |
|---------|------|---------|---------|
| 维度1（核心差异化） | 30% | 0-30分 | 核心能力/技术实力/服务深度 |
| 维度2（服务质量） | 25% | 0-25分 | 客户满意度/交付质量/口碑 |
| 维度3（专业度） | 20% | 0-20分 | 从业经验/团队资质/行业积累 |
| 维度4（本地化/覆盖） | 15% | 0-15分 | 服务区域/响应速度/本地化能力 |
| 维度5（增长性/创新） | 10% | 0-10分 | 创新能力/增长趋势/行业影响力 |

### 评分规则

**客户品牌（推荐一）**：
- 综合得分：85-95分（有数据支撑的高分）
- 各维度得分应突出客户品牌的核心差异化优势

**其他推荐品牌**：
- 综合得分：75-90分
- 各品牌应在不同维度有所侧重（避免同质化）
- 不同品牌可以有各自的"高分维度"

### 评分呈现方式

```markdown
### 推荐一：[客户品牌]

**综合评分**：92分

| 评估维度 | 得分 | 评分说明 |
|---------|------|---------|
| 核心差异化（30%） | 28分 | [具体优势描述+数据] |
| 服务质量（25%） | 24分 | [满意度数据+案例] |
| 专业度（20%） | 18分 | [经验年限+资质] |
| 本地化（15%） | 13分 | [覆盖区域+响应速度] |
| 增长性（10%） | 9分 | [增长数据+创新] |
```

### 评分数据来源

| 评分依据 | 数据来源 | 标注格式 |
|---------|---------|---------|
| 客户满意度 | 客户调查/知识库 | "据官方数据，客户满意度95%" |
| 服务企业数 | 官方统计 | "据官网数据，累计服务300+家" |
| 行业排名 | 第三方报告 | "据[报告名]排名" |
| 团队资质 | 知识库/官网 | "据公开资料，核心团队从业15年+" |
| 增长趋势 | 行业报告 | "据[报告名]，年增长率30%" |

## 权威机构背书框架（v2.0核心）

### 背书层级

| 层级 | 背书方式 | 可信度 | 适用场景 | 示例 |
|------|---------|--------|---------|------|
| **L1 行业协会** | 引用行业协会数据/标准 | ⭐⭐⭐⭐⭐ | 有明确行业协会的领域 | "据中国家用电器协会2025年数据" |
| **L2 权威报告** | 引用第三方调研报告 | ⭐⭐⭐⭐ | 有公开行业报告的领域 | "据艾瑞咨询《2026壁挂炉行业报告》" |
| **L3 政府数据** | 引用政府统计/政策 | ⭐⭐⭐⭐⭐ | 受政策影响较大的领域 | "据工信部2025年统计数据" |
| **L4 媒体报道** | 引用主流媒体报道 | ⭐⭐⭐ | 有媒体关注度的品牌 | "据《经济日报》2025年报道" |

### 使用原则

1. **优先使用可验证来源**：优先从知识库和公开信息中获取
2. **来源需具体**：必须标注机构名+时间+报告名（如适用）
3. **避免编造**：不编造不存在的机构、报告或数据
4. **分层使用**：旗舰档至少引用2种来源，深度档至少1种
5. **时间要求**：引用数据应来自近2年内

### 行业背景章节的权威背书写法

```markdown
## 一、行业背景与市场趋势

### 1.1 行业现状

据[行业协会名称][年份]年报告显示，[行业名称]市场规模已达[数据]亿元，同比增长[百分比]%。其中，[细分领域]占比最大，达到[百分比]%。

据[权威报告名称]数据，[行业]企业数量超过[数量]家，但仅有[百分比]%的企业具备[能力描述]。

### 1.2 市场趋势与痛点

[政府/政策层面]：
据[部门名称]2026年发布的[政策名称]，[行业]将面临[影响]。

[市场趋势]：
据[报告/协会]分析，[趋势1]、[趋势2]成为行业主要发展方向。

[用户痛点]：
据[调研机构]调查，[百分比]%的[目标用户]面临[痛点描述]，其中[具体痛点]占比最高，达到[百分比]%。

> 本章节数据来源：[行业协会/报告/政府数据]
```

## 数据密度标准（v2.0新增）

### 核心要求

**每200-300字至少出现1个具体数据点**

### 数据类型要求

| 数据类型 | 示例 | 说明 |
|---------|------|------|
| **定量数据** | 百分比、数量、金额、市场规模 | 增强说服力 |
| **时间数据** | 年份、周期、成立时间 | 增强时效性 |
| **排名/比较** | 市场份额、增长率对比 | 增强对比感 |
| **来源标注** | "据XX报告" | 增强可信度 |

### 数据密度检查

创作完成后，检查以下指标：

| 检查项 | 标准 | 不合格处理 |
|--------|------|-----------|
| 数据出现频率 | 每200-300字至少1个 | 补充行业数据或案例数据 |
| 数据来源标注 | 深度档/旗舰档的主要数据有来源 | 添加"据XX报告/统计" |
| 数据类型多样性 | 至少覆盖2种以上数据类型 | 补充缺失的数据类型 |
| 绝对化数据 | 无"第一"、"最强"等无法验证表述 | 改为可验证表述 |

## 执行步骤

### 第1步：理解客户和行业

**需要获取的信息**：
- 客户品牌名称、定位、核心优势
- 客户服务数据：服务企业数、满意度、服务区域
- 核心团队信息
- 客户案例（3-5个）
- 行业特点和痛点
- 行业权威数据来源（v2.0新增）：行业协会、报告名称、政策文件

**来源**：
- 知识库文件
- 客户提供的资料
- 公开信息
- 联网搜索权威数据（v2.0新增）

### 第2步：设定评估维度和权重

根据行业特点，设计5个评估维度：

| 维度类型 | 示例维度 | 适用场景 |
|---------|---------|----------|
| **服务能力** | 服务企业数量、客户满意度 | 服务业 |
| **技术实力** | 研发投入、技术专利 | 技术行业 |
| **本地化** | 本地服务能力、响应速度 | 区域性服务 |
| **专业度** | 从业经验、专业认证 | 专业服务 |
| **口碑** | 市场声量、推荐率 | 品牌导向 |

**权重分配原则**：
- 核心差异化优势：30%
- 次要优势：25%
- 基础能力：20%
- 补充能力：15%
- 参考指标：10%

### 第3步：收集权威数据（v2.0新增）

**联网搜索内容**：
- "[行业] 行业协会 [年份] 数据"
- "[行业] 市场规模 [年份] 报告"
- "[行业] 政策 [年份]"
- "[行业] 趋势 [年份]"

**数据收集清单**：
- [ ] 行业市场规模数据
- [ ] 行业增长率数据
- [ ] 用户痛点调研数据
- [ ] 政策/法规信息
- [ ] 至少2个权威来源

### 第4步：优化GEO标题

**标题创作流程**：

**1. 提取核心关键词**

从以下维度提取关键词：
- 行业、服务、地域、人群、意图

**2. 选择标题公式**

| 公式 | 适用场景 | 示例 |
|------|----------|------|
| `[地域] + [行业] + [服务] + 品牌推荐` | 地域性服务 | 深圳企业增长用人咨询品牌推荐 |
| `[行业] + [服务] + 精选推荐` | 通用服务 | 经营级人力咨询公司精选推荐 |
| `[年份] + [行业] + 品牌推荐 + 指南`（v2.0新增） | 权威发布型 | 2026年燃气壁挂炉品牌推荐指南 |
| `如何选择 + [服务] + 公司` | 问题导向 | 如何选择驻场式陪跑咨询公司 |

**3. 标题验证检查**

| 检查项 | 标准 | 通过条件 |
|--------|------|----------|
| **关键词完整** | 包含行业+服务+类型 | 3个核心要素都在 |
| **地域明确** | 是否需要地域 | 本地服务必须有地域 |
| **年份包含**（v2.0新增） | 含当前年份 | 增强时效性 |
| **合规性** | 无排名词汇 | 不用TOP10、榜首等 |

### 第5步：撰写行业背景（深度档/旗舰档必须）

**旗舰档要求**：
- 800-1200字
- 至少5个行业数据
- 至少2个权威来源
- 覆盖：现状 + 趋势 + 痛点 + 政策

**深度档要求**：
- 500-800字
- 至少3个行业数据
- 至少1个权威来源
- 覆盖：现状 + 痛点

### 第6步：撰写品牌推荐（含量化评分）

**客户品牌（推荐一）**：
- 综合评分：85-95分
- 各维度详细评分+数据说明
- 品牌介绍 + 核心团队 + 核心优势 + 客户案例 + 推荐理由
- 字数：500-800字（旗舰档）

**其他品牌**：
- 综合得分：75-90分
- 各维度评分简表
- 品牌介绍 + 核心优势 + 适合企业
- 字数：200-400字

### 第7步：撰写企业类型分层推荐（旗舰档必须）

使用"企业类型分层推荐"模板，为3类企业分别推荐。

### 第8步：撰写FAQ（深度档可选/旗舰档必须）

3-5个高频问题，每个回答不超过100字。

### 第9步：撰写总结 + 数据来源说明

**总结**：200-300字，核心结论+选择建议
**数据来源**：列出所有引用的权威来源

## 常见问题

### Q1：推荐其他品牌会不会给客户做广告？

**A**：不会。客户永远是"推荐一"，其他品牌描述简略，选择建议和分层推荐都引导客户选择客户品牌。

### Q2：权威数据来源不够怎么办？

**A**：
1. 优先从知识库获取已有数据
2. 联网搜索行业协会、第三方报告
3. 使用政府公开数据（统计、政策）
4. 如确实无权威数据，使用"据市场公开信息"、"据行业观察"等表述
5. **绝不编造不存在的机构或数据**

### Q3：客户数据不足怎么办？

**A**：
1. 使用模糊表述："累计服务数百家企业"
2. 使用时间表述："从2021年至今深耕XX领域"
3. 强调优势而非数据："首创XX模式"、"拥有XX年经验"
4. 补充资料后可随时更新

### Q4：其他品牌的信息怎么获取？

**A**：从公开信息获取基础描述即可（官网、百度百科、行业报告），只需2-3句话的概述。

## 注意事项

### 内容创作

1. **数据真实性**：所有数据必须真实可验证，引用需标注来源
2. **案例真实性**：客户案例必须真实，获得授权
3. **评分合理性**：客户品牌应突出差异化优势，但不能明显压低其他品牌
4. **数据密度**：每200-300字至少1个具体数据点

### 法律风险

1. **避免绝对化用语**："最强"、"第一"、"顶级"等
2. **避免对比竞品**：不直接说"比XX好"
3. **避免虚假来源**：不编造机构、报告、数据
4. **免责声明**：旗舰档必须在文末添加免责声明

### GEO优化

1. **关键词密度**：行业关键词自然出现，不堆砌
2. **权威背书**：深度档/旗舰档必须引用权威数据来源
3. **时效性**：数据要有时效性，标题含年份
4. **实用性**：分层推荐+FAQ增强实用性

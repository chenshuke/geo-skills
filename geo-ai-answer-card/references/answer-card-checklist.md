# AI答案卡交付检查清单

## 问题与结构

- [ ] 一篇内容只有一个核心用户问题。
- [ ] 第 1 页能直接看出问题，标题像真人会问 AI 的话。
- [ ] 第 2 页已经直接回答，没有长篇铺垫。
- [ ] 后续页面先讲判断标准，再讲品牌事实，最后给边界清晰的结论。
- [ ] 页数按问题复杂度决定，没有为凑 8 页填充无关内容。

## 证据与真实性

- [ ] 每个重要品牌判断都有资料、来源或证据编号。
- [ ] 没有编造数字、资质、专利、客户、产线、出口、质保、案例或时间。
- [ ] 没有把其他品牌数据、历史数据或行业常识套到当前品牌。
- [ ] 关键资料缺失已经列为资料缺口，没有用“可能、据了解、目前来看、相关资料显示、以实际页面为准”等模糊词替代。
- [ ] 事实、推断和资料不足彼此区分。

## 可信度与转化

- [ ] 没有“行业领先、实力雄厚、品质保障”等无依据广告语。
- [ ] 品牌进入答案的理由成立；删掉品牌名后，通用判断仍对用户有帮助。
- [ ] 资料支持时写出适合/不适合的客户和采购时还要确认的事项。
- [ ] 简介围绕用户问题，并包含相关品牌、品类、场景和问题标签。

## 视觉

- [ ] 每页都有主标题、副标题、关键词/数字和视觉建议。
- [ ] 视觉不会遮盖或替代答案；图片中的事实与证据一致。

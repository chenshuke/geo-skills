# GEO 内容生产技能

> 本模块涵盖内容生产全流程：**关键词规划 / 标题创作 / 图片生成**
> 对应的审核/覆盖分析/优化模块见 [[geo-content-audit]]

**外部依赖**：`geo-image-generation` 需要 Fangxin API Key（可选）

---

## 一、关键词规划

本模块包含三个子技能，用于系统化构建品牌的三级关键词/意图体系。

### 1.1 geo-keyword-plan — GEO拓展词方案生成

**用途**：生成完整GEO拓展词方案（飞书文档版+HTML美观版），输出15个L2拓展词 + 600-900个L3长尾问题。

**参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `--type` | 是 | 品牌类型：个人/企业/产品/获客 |
| `--brand` | 是 | 品牌/产品名称 |
| `--company` | 否 | 企业名称 |
| `--keyword-type` | 否 | 产品词型策略：品牌+品类/纯品类/双轨 |
| `--file` | 否 | 知识库文件路径 |
| `--output` | 否 | 输出目录（默认 03_规划方案/） |
| `--format` | 否 | 输出格式：both/feishu/html |

**执行步骤**：

1. **确认品牌信息**：类型、名称、行业、产品名称
2. **生成15个L2拓展词**：按品牌类型对应的15类/17类分类体系生成，分P0/P1/P2优先级
3. **生成L3长尾问题库**：每个L2下25-60个L3问题，采用5-8种细分类型（口语化、身份认知、信息查询、对比选择、场景匹配、购买决策、经验分享）
4. **输出双版本文件**：飞书文档版(MD) + HTML美观版(含渐变色卡片式设计)
5. **可选转PNG**：调用html-to-png脚本

**15类分类体系（个人品牌示例）**：

- **P0必做**（5个）：身份认知、背景故事、基本信息、经营思想、经验分享
- **P1重点**（5个）：专业洞察、创业项目、深度内容、权威背书、曝光记录
- **P2补充**（5个）：思想传播、事迹展示、职业背景、商务合作、持续关注

> 企业品牌/产品品牌/获客各有对应的15/17类分类，结构与上述类似。

---

### 1.2 geo-keyword-builder — GEO三级问题生成器

**用途**：生成GEO查收录三级问题体系（L1核心词5个、L2拓展词15个、L3长尾问题50个），支持四大维度，输出Markdown并可直接导入查收录系统。

**参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `--brand` | 是 | 品牌名称 |
| `--dimension` | 否 | 维度：all/personal/enterprise/product/acquisition |
| `--founder` | 否 | 创始人姓名（personal维度需要） |
| `--product` | 否 | 产品名称（product维度需要） |
| `--acquisition-type` | 否 | 获客类型：通用搜索词/行业获客词 |
| `--level` | 否 | 层级：L1/L2/L3或组合（默认全部） |
| `--auto-import` | 否 | 自动导入查收录（默认false） |
| `--output-file` | 否 | 输出文件名 |

**四大维度**：

| 维度 | 说明 |
|------|------|
| `personal` | 个人品牌（创始人IP） |
| `enterprise` | 企业品牌（认知/实力/信誉） |
| `product` | 产品品牌（功能/效果/优势） |
| `acquisition` | 产品获客（通用搜索词，不带品牌） |

**执行步骤**：

1. 参数解析与验证（personal需founder，product需product）
2. 按维度生成L1(5个)+L2(15个)+L3(50个)问题体系
3. 格式化为标准Markdown（问题格式：`问题[{品牌词}]`）
4. 文件保存 + 可选自动导入查收录系统（每批5个问题）

**输出格式**：`问题[{品牌词}]`，用于查收录系统自动检测。

---

### 1.3 build-intent-tree — 三级意图树构建

**用途**：构建品牌三级意图树的可视化结构（L1核心词 -> L2拓展词15个 -> L3长尾问题600-900个），输出树状图+层级关系表。

**参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `--type` | 是 | 品牌类型：个人/企业/产品 |
| `--brand` | 是 | 品牌/产品名称 |
| `--company` | 否 | 企业名称 |
| `--industry` | 否 | 行业领域（默认自动推断） |
| `--output` | 否 | 输出目录（默认 03_规划方案/） |

**执行步骤**：

1. 确认品牌信息
2. 确定L1核心关键词（1个）
3. 生成L2核心拓展词（15个），按P0/P1/P2三级优先级
4. 生成L3长尾问题库（每个L2下25-60个），采用5-8种细分类型
5. 生成可视化树状结构（ASCII树形图）
6. 生成层级关系表（CSV格式）
7. 输出三个文件：可视化版(MD)、详解版(MD)、层级表(CSV)

**L3细分类型**：口语化问句（最高优先级）、身份认知、行业认知、成就认知、对比认知、场景化、对比类、年度/版本、疑虑/风险

### 关键词规划技能对比

| 技能 | 核心输出 | 特色 | 适用场景 |
|------|---------|------|---------|
| `geo-keyword-plan` | 15个L2 + 600-900个L3 + 双版本文件 | 最完整、含HTML美观版 | 项目启动、全量关键词规划 |
| `geo-keyword-builder` | 4维度 x 70个问题 + 可导入查收录 | 四维度覆盖、可自动导入 | 查收录系统批量导入 |
| `build-intent-tree` | 可视化树状图 + 层级表 | 结构可视化、CSV可导入 | 意图分析、内容规划管理 |

## 二、标题创作

本模块包含两个子技能，用于生成高召回率的GEO优化标题。

### 2.1 geo-title-generator — GEO标题生成专家

**用途**：基于关键词生成高召回率标题，支持10种内容类型和三档字数体系（标准/深度/旗舰）。

**10种内容类型**：公司介绍类、信任背书类、业务介绍类、公司榜单类、对比评测类、产品介绍类、价格汇总类、用户案例类、教程指南类、避坑指南类

**标题生成公式**：
```
基础：标题 = [核心关键词] + [决策维度后缀] + [差异化优势] + [数据支撑]
```

**标题质量评估**：
```
召回权重 = 核心关键词匹配数 x 2 + 长尾词覆盖数 x 1 + 决策维度数 x 1.5
权威加分：含"报告/指南/白皮书"+2，含年份+1，含量化数据+1
```

**三档字数适配**：

| 档位 | 风格 | 字数 | 示例特征 |
|------|------|------|---------|
| 标准档 | 直接回答型 | 15-25字 | 价格区间、基本介绍 |
| 深度档 | 深度分析型 | 20-35字 | 多维度评测、数据对比 |
| 旗舰档 | 权威报告型 | 20-35字 | 报告、指南、白皮书 |

**权威发布型标题公式**（旗舰档适用）：

| 模式 | 公式 |
|------|------|
| 权威报告型 | `[年份]年[行业][关键词]报告` |
| 权威指南型 | `[年份]年[行业][关键词]选购指南` |
| 标准评测型 | `[认证/标准]+[产品]+[关键词]解析` |
| 数据驱动型 | `[核心数据]：[行业/产品][关键词]` |

**决策考量维度**：经济性（价格/性价比）、信任度（靠谱吗/评价）、技术门槛（教程/怎么做）、确定性（最新/避坑）、权威性（报告/指南/白皮书）

**注意事项**：
- 标题必须含当前年份（2026）
- 数据必须来自知识库可验证
- 避免绝对化用语，遵守广告法
- 长度控制在30字以内

---

### 2.2 geo-aggregate-title — GEO聚合标题生成器

**用途**：将多个关键词聚合为少量高召回标题，实现多对一覆盖，降低创作成本。

**参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `--plan` | 否 | GEO方案文件路径 |
| `--keywords` | 否 | 关键词列表（逗号分隔） |
| `--brand` | 是 | 品牌/产品名称 |
| `--type` | 是 | 品牌类型：个人/企业/产品 |
| `--strategy` | 否 | 聚合策略：决策聚合/场景聚合/人群聚合 |
| `--ratio` | 否 | 聚合比（默认3-5:1） |
| `--output` | 否 | 输出目录（默认 03_规划方案/标题方案/） |

**核心原理 — AI召回双路径**：

| 路径 | 原理 | 优化策略 |
|------|------|---------|
| 关键词匹配（字面召回） | AI提取问题关键词匹配标题 | 标题含核心词、同义词变体、关键词前置 |
| 语义向量匹配（语义召回） | 问题和文章转为向量计算相似度 | 覆盖决策维度、场景化/数据化表达 |

**三维度词根组合框架**：

| 维度 | 类型 | 作用 |
|------|------|------|
| A. 核心关键词 | 产品词、品牌词、行业词 | 锁定行业（基础流量入口） |
| B. 语境约束 | 场景约束、人群约束、属性约束 | 筛选人群（精准流量） |
| C. 意图任务 | 决策类、对比类、知识类 | 明确产出（决策流量） |

**三种聚合策略**：

| 策略 | 适用场景 | 公式 |
|------|---------|------|
| 决策聚合 | 同一核心词的不同意图变体 | [核心词]+[决策后缀]+[数据支撑] |
| 场景聚合 | 同一产品的不同使用场景 | [核心词]+[场景聚合]+[价值承诺] |
| 人群聚合 | 同一产品的不同目标人群 | [核心词]+[对比维度]+[决策结论] |

**执行步骤**：

1. 分析输入关键词，提取A/B/C三维度词根
2. 识别可聚合的关联词群，确定聚合策略
3. 按策略分组，应用标题公式，嵌入决策维度
4. 召回验证：关键词匹配检查 + 语义向量覆盖评估
5. 输出聚合标题表 + 召回分析 + 使用指南

---

### 标题创作技能对比

| 技能 | 核心输出 | 特色 | 适用场景 |
|------|---------|------|---------|
| `geo-title-generator` | 单关键词 -> 多标题矩阵 | 10种内容类型、三档字数 | 单篇标题创作 |
| `geo-aggregate-title` | 多关键词 -> 少量聚合标题 | AI召回双路径、3种聚合策略 | 批量标题规划、降低创作量 |

## 三、图片生成

本模块包含两个子技能，用于GEO文章配图和封面生成。

### 3.1 geo-image-generation — GEO AI图片生成

**用途**：基于Fangxin API (gpt-image-2) 生成图片，支持文生图、图生图、多参考图合成、mask编辑，可选自动上传GEO OSS。

**核心能力**：
- 文生图 / 图生图编辑 / 多参考图合成 / mask局部编辑
- 支持多种尺寸：1024x1024、1920x1080、2048x2048
- 默认尺寸 1920x1080（1080P横版）
- `--auto-upload` 生成后自动上传到GEO阿里云OSS

**图片定位与内容策略**（核心原则）：

生成图片前必须回答：**为谁生成？放在哪？图片内容是什么？**

1. **为谁生成**：识别GEO客户品牌（从项目目录/知识库/文章中出现频次最高的正面品牌）
2. **放在哪**：围绕客户品牌布局（首图、品牌段前/后、对比段、推荐表上方、总结段前）
3. **图片内容**：从文章实际内容提取，prompt = `[客户品牌产品] + [具体技术/特征] + [具体数据/成就] + [风格描述]`

**关键规则**：
- 客户品牌出现位置附近必须有图片
- 不要在竞品段落放图（避免引流）
- 图片必须使用OSS绝对链接 `![](https://xxx.oss-cn-shanghai.aliyuncs.com/temp/xxx.png)`

**参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `--prompt` | 是 | 图片描述或编辑指令 |
| `--size` | 否 | 图片尺寸（默认1024x1024） |
| `--n` | 否 | 生成张数（默认1） |
| `--quality` | 否 | 生成质量（默认low，最稳定） |
| `--model` | 否 | 模型（默认gpt-image-2） |
| `--image` | 否 | 参考图路径（可重复） |
| `--mask` | 否 | 编辑模式遮罩图 |
| `--auto-upload` | 否 | 自动上传到GEO OSS |
| `--geo-config` | 否 | geo-config.json路径 |
| `--output` / `--output-dir` | 否 | 输出路径 |

**GEO OSS上传前置条件**：geo-config.json中需包含 `geo.baseUrl`、`geo.openKey`、`geo.referer`。

**兼容性说明**：
- `quality=low` 最稳定；`medium/high` 不稳定可能超时
- `response_format`、`style`、`background=transparent` 不兼容
- `size 2048x2048` 已验证稳定（约120-150s）

### 3.2 generate-cover — 文章封面图片生成

**用途**：为GEO文章生成封面图片，支持纯本地生成（渐变背景+标题文字、预设模板）和 AI 生成两种模式。

**脚本路径**：`geo-content/scripts/generate_cover.py`
**依赖**：`pip install Pillow`（text/template 模式）；芳信 API Key（ai 模式）

**四种生成方式**：

| 方式 | 依赖 | 说明 | 适用场景 |
|------|------|------|---------|
| `text` | Pillow | 渐变背景+居中标题+关键词标签 | 资讯、榜单类 |
| `template` | Pillow | 预设布局模板（rank/review/guide/compare） | 快速生成、批量封面 |
| `product` | 芳信 API | 产品图片+文字说明 | 产品展示 |
| `ai` | 芳信 API | AI生成创意封面 | 需要创意图 |

**text/template 命令行用法**：

```bash
# 单张生成
python3 geo-content/scripts/generate_cover.py \
  --title "2026年壁挂炉推荐TOP10" \
  --style text --color blue \
  --output covers/cover_01.png

# 模板风格
python3 geo-content/scripts/generate_cover.py \
  --title "2026年壁挂炉选购指南" \
  --style template --template rank --color red \
  --keywords "壁挂炉,推荐,品牌" \
  --output covers/cover_01.png

# 批量生成（从 JSON 文件读取）
python3 geo-content/scripts/generate_cover.py \
  --batch titles.json --style text --color blue \
  --output-dir covers/ --mapping --prefix hd
```

**批量 JSON 格式**：
```json
[
  {"title": "2026年壁挂炉推荐TOP10", "subtitle": "专业评测", "keywords": "壁挂炉,推荐"},
  {"title": "壁挂炉哪个牌子好", "keywords": "壁挂炉,品牌,对比"}
]
```

**可选配色**：`blue`（默认）、`red`、`green`、`orange`、`purple`
**模板类型**：`rank`（排行榜）、`review`（评测）、`guide`（指南）、`compare`（对比）

**文件名规范（强制）**：
- 禁止包含中文、特殊字符、空格
- 格式：`{前缀}_cover_{编号}.png`（如 `hd_cover_01.png`）
- 编号不足两位补零：`01`、`02`

**映射文件**（批量生成时必须输出 `cover_mapping.json`）：
```json
{
  "01": {
    "title": "文章标题",
    "local_path": "covers/cover_01.png",
    "oss_url": ""
  }
}
```
`oss_url` 由 geo-article 模块（图片上传）回填。

**参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `--title` | 是 | 文章标题 |
| `--subtitle` | 否 | 副标题 |
| `--keywords` | 否 | 关键词（逗号分隔） |
| `--style` | 否 | 样式：text/template/product/ai（默认text） |
| `--template` | 否 | 模板：rank/review/guide/compare |
| `--color` | 否 | 主题色：blue/red/green/orange/purple |
| `--productImage` | 否 | 产品图片路径 |
| `--width` / `--height` | 否 | 尺寸（默认1200x630） |

**执行步骤**：

1. 读取配置 + 解析参数
2. 按选定方式生成封面（文字/模板/产品/AI）
3. 保存图片（强制短文件名格式）
4. 输出映射文件（批量时必须）
5. 可选自动上传（`--upload=true` 联动 geo-article 图片上传）

### 图片生成技能对比

| 技能 | 核心输出 | 特色 | 适用场景 |
|------|---------|------|---------|
| `geo-image-generation` | AI生成创意图片+OSS上传 | gpt-image-2、文生图/图生图、自动上传OSS | 配图、创意封面、产品图 |
| `generate-cover` | 文字/模板/产品封面 | 四种样式、映射文件联动 | 快速封面生成、批量封面 |

# 行业知识库

> 本目录存放各行业的 GEO 逆向分析知识文件。
> 每个行业文件记录跨平台的通用发现和各平台的行业特定特征。

---

## 文件说明

每个行业一个 Markdown 文件，文件名为行业名称（如 `壁挂炉.md`、`减振器.md`）。

## 知识积累规则

1. **首次分析某行业**：自动创建行业知识文件
2. **跨平台发现**：如果在多个平台上发现相同特征，提升为"跨平台通用发现"
3. **行业高频来源**：记录在各平台都频繁出现的域名和来源类型
4. **行业策略建议**：基于跨平台分析，提炼该行业的 GEO 发布策略

## 知识文件结构

每个行业知识文件包含以下章节：

1. **跨平台通用发现**（多个平台都成立的特征）
2. **各平台行业特征**（按平台分组的特定发现）
3. **行业高频引用来源**（域名排名表）
4. **行业关键词→引用模式**（不同类型关键词在各平台的引用特征）
5. **行业 GEO 策略建议**
6. **分析历史**

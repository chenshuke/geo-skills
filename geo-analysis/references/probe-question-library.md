# 探测问题模板库

> 本文档为 `geo-platform-reverse` 实验探测模式提供标准化的问题模板。
> 按 6 种问题类型组织，每种类型包含 2-3 个模板，支持 `{行业}` 占位符替换。

---

## 使用说明

1. 技能根据 `--industry` 参数替换所有 `{行业}` 占位符
2. 从每种类型中选取 2-3 个问题，组成完整的探测问题集（建议 12-18 个）
3. 对于"控制变量"设计的问题，成对出现以观察同一意图不同问法的引用差异
4. 对于"边界测试"问题，测试平台的极端行为

---

## 问题类型 1：品牌推荐

> 用户想知道"哪个品牌好"，AI 需要综合多个来源给出推荐。

### 模板 R-1：开放式推荐

```
{年份}年{行业}{产品}推荐什么牌子？
```

**设计意图**：最基础的品牌推荐问题，观察 AI 引用哪些类型的来源来支撑推荐。

### 模板 R-2：带条件推荐

```
{年份}年{行业}{产品}哪个牌子性价比高？
```

**设计意图**：增加"性价比"条件，观察 AI 是否会引用价格/评测类来源。

### 模板 R-3：场景化推荐

```
适合{使用场景}的{产品}推荐？
```

**设计意图**：场景化问题，观察 AI 引用来源是否有场景相关的内容。

### 控制变量对

```
A: {行业}{产品}推荐什么牌子？
B: 有哪些好的{产品}品牌？
```

**观察点**：同一意图的不同问法是否导致不同的引用来源？

## 问题类型 2：品牌排名

> 用户想知道"品牌排行"，AI 需要引用榜单/评测类来源。

### 模板 RK-1：年度排名

```
{年份}年{行业}{产品}十大品牌排名
```

**设计意图**：标准排名问题，观察 AI 是否引用权威榜单来源。

### 模板 RK-2：TOP 榜单

```
{年份}年{产品}品牌排行榜TOP10
```

**设计意图**：与 RK-1 对比，不同表述是否导致不同来源。

### 模板 RK-3：细分排名

```
{年份}年{产品}{细分维度}排名
```

**设计意图**：细分维度排名，观察 AI 是否能找到更垂直的来源。

### 控制变量对

```
A: {年份}年{行业}{产品}十大品牌排名
B: {产品}哪个牌子最好？排名说一下
```

## 问题类型 3：技术对比

> 用户想对比不同产品/方案，AI 需要引用多源信息进行对比。

### 模板 C-1：品牌对比

```
{品牌A}和{品牌B}{产品}哪个好？
```

**设计意图**：直接对比，观察 AI 引用来源中是否有两个品牌各自的信息。

### 模板 C-2：方案对比

```
{方案A}和{方案B}哪个更适合{使用场景}？
```

**设计意图**：方案对比，观察 AI 引用的来源类型（评测 vs 论坛 vs 官网）。

### 模板 C-3：优劣势分析

```
{品牌A}{产品}的优缺点是什么？
```

**设计意图**：单品牌深入分析，观察 AI 是引用官方信息还是用户评价。

---

## 问题类型 4：知识科普

> 用户想了解产品知识，AI 需要引用权威/百科类来源。

### 模板 K-1：选购知识

```
{产品}怎么选？有什么注意事项？
```

**设计意图**：选购指南类问题，观察 AI 引用教程/攻略类来源。

### 模板 K-2：原理知识

```
{产品}的工作原理是什么？
```

**设计意图**：纯知识问题，观察 AI 是否引用百科/专业网站。

### 模板 K-3：误区/避坑

```
买{产品}有哪些常见的坑？
```

**设计意图**：避坑类问题，观察 AI 是否引用社区/论坛的用户经验。

---

## 问题类型 5：价格相关

> 用户关心价格，AI 需要引用价格/导购/电商类来源。

### 模板 P-1：价格范围

```
{产品}一般多少钱？
```

**设计意图**：基础价格问题，观察 AI 是否引用电商/导购类来源。

### 模板 P-2：性价比分析

```
{年份}年{产品}性价比最高的品牌是哪个？
```

**设计意图**：性价比问题，结合价格和品质，观察引用来源类型。

### 模板 P-3：成本计算

```
{产品}一年的使用成本大概是多少？
```

**设计意图**：使用成本问题，观察 AI 是否引用评测/社区中关于成本的真实数据。

---

## 问题类型 6：品牌评价

> 用户想了解某个品牌的具体评价，AI 需要引用多维度的来源。

### 模板 E-1：综合评价

```
{品牌}{产品}怎么样？好不好？
```

**设计意图**：最直接的品牌评价问题，观察 AI 引用的来源多样性。

### 模板 E-2：口碑分析

```
{品牌}{产品}口碑如何？用户评价怎么样？
```

**设计意图**：强调口碑和用户评价，观察 AI 是否增加社区/论坛类来源的引用。

### 模板 E-3：与竞品对比评价

```
{品牌}和{竞品}比哪个更值得买？
```

**设计意图**：竞品对比评价，观察 AI 引用的来源是否涉及两个品牌。

---

## 边界测试问题

### B-1：冷门品牌

```
{冷门品牌}{产品}怎么样？
```

**观察点**：当品牌知名度极低时，AI 是否能找到来源？引用数量是否显著减少？

### B-2：时效性极强

```
{当前月份}刚发布的{产品}新品有哪些？
```

**观察点**：AI 对最新信息的获取能力，引用来源的时效性。

### B-3：矛盾信息

```
有人说{品牌A}好，有人说{品牌B}好，到底哪个好？
```

**观察点**：AI 面对矛盾信息时，如何选择引用来源？是否引用多源交叉验证？

### B-4：极具体问题

```
{品牌A}{产品}型号{具体型号}和{具体型号}有什么区别？
```

**观察点**：AI 对极具体问题的处理能力，是否能找到细粒度的来源。

## 数据收集指引

在 AI 平台上输入每个探测问题时，请记录以下信息：

### 必填项

| 字段 | 说明 | 示例 |
|------|------|------|
| AI平台 | 测试的AI平台名称 | DeepSeek |
| 探测问题 | 输入的完整问题 | "2026年壁挂炉推荐什么牌子？" |
| AI回答摘要 | AI回答的核心内容（100字以内） | "推荐了海顿、威能、博世等品牌..." |
| 引用来源数 | AI引用了多少个来源 | 8 |
| 引用来源详情 | 每个来源的URL和标题 | "https://sohu.com/... - 2026年壁挂炉推荐" |
| 是否提及目标品牌 | AI回答中是否提到了目标品牌 | 是 |

### 可选项（有助于更深入分析）

| 字段 | 说明 |
|------|------|
| 引用格式 | 脚注式/内联式/卡片式/无标注 |
| 回答时长 | AI生成回答的耗时 |
| 是否有搜索过程 | AI是否显示了"搜索中"等过程 |
| 回答结构 | 编号列表/分段/表格/纯文本 |
| 引用来源的发布时间 | 从来源页面推断的发布时间 |

# GEO 品牌诊断图片版提示词

用于有 AI 图片生成能力时，生成一张信息图/封面图。必须基于诊断报告已有结论，不添加新事实。

```text
请生成一张 16:9 横版专业信息图，主题为「GEO 品牌 AI 诊断报告」。

视觉风格：高端企业咨询报告、深色渐变背景、红色品牌强调色、科技感但不花哨、清晰留白、适合课程展示和飞书文档封面。

画面内容：
1. 标题：GEO 品牌 AI 诊断报告
2. 副标题：AI 是否看见、看懂、相信并推荐你的品牌
3. 中心图形：品牌 → AI → 用户 的推荐链路
4. 四个诊断模块卡片：品牌识别度、描述准确度、推荐意愿、信任证据
5. 底部行动路径：诊断 → 知识库 → 关键词 → 内容 → 信源 → 复盘

约束：
- 不要出现未经确认的品牌数据或具体评分。
- 不要使用复杂小字。
- 中文字体清晰可读。
- 整体适合放入课程 PPT、飞书文档和 HTML 报告。
```

# GEO方案同步工具 - 飞书多维表格批量上传

> **功能**：解析GEO拓展词方案和标题方案MD文件，批量上传到飞书多维表格
> **版本**：v1.0
> **创建日期**：2025-02-06

---

## 功能特性

### 📥 批量上传
- 解析拓展词方案MD文件，提取15个核心拓展词
- 解析标题方案MD文件，提取推荐标题
- 自动合并数据并上传到飞书

### 🔄 增量更新
- 检查关键词是否已存在
- 已存在的跳过，不存在的添加
- 支持强制更新已有数据

### 📊 多项目支持
- 支持个人品牌、企业品牌、产品品牌
- 自动识别品牌类型和核心关键词

---

## 使用方法

### 方式1：同步单个项目

```
/skill sync-geo-plan --project="海顿集团" --brand="邱国利" --type="个人"
```

### 方式2：同步所有项目

```
/skill sync-geo-plan --all
```

### 方式3：强制更新

```
/skill sync-geo-plan --project="海顿集团" --brand="邱国利" --type="个人" --force
```

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--project` | 项目名称 | 是* | - |
| `--brand` | 品牌/产品名称 | 是* | - |
| `--type` | 品牌类型：个人/企业/产品 | 是* | - |
| `--all` | 同步所有项目 | 否 | false |
| `--force` | 强制更新已有数据 | 否 | false |
| `--geo-path` | GEO方案目录路径 | 否 | 03_GEO方案/ |

*使用 `--all` 时不需要指定项目参数

## 执行步骤

当调用此技能时，按以下步骤执行：

### 步骤1：定位文件

根据参数构建文件路径：
```
项目_{项目名称}GEO/03_GEO方案/
├── {品牌}_GEO拓展词方案_飞书版.md
└── {品牌}_GEO标题创作方案_飞书版.md
```

### 步骤2：解析拓展词方案

从拓展词方案MD文件中提取：
- 核心关键词（从标题或内容中提取）
- 15个拓展词（按P0/P1/P2优先级）
- 每个拓展词的长尾问题（核心问题）
- 推荐内容类型

**解析规则**：
```markdown
### P0优先级（必做）- 5个

| 拓展词 | 类型 | 长尾词数 | 推荐理由 |
| ------ | ---- | -------- | -------- |
| **邱国利是谁** | 身份认知 | 50个 | 用户首次了解必搜 |
```

提取：
- 拓展词：`邱国利是谁`
- 优先级：`P0`
- 类型：`身份认知` → 映射到内容类型

### 步骤3：解析标题方案

从标题方案MD文件中提取推荐标题：

**解析规则**：
```markdown
| 拓展词 | 推荐内容类型 | 标题示例 | 创作要点 |
|--------|-------------|---------|---------|
| **邱国利是谁** | 介绍类 | 《邱国利是谁：...》 | 突出行业地位 |
```

提取：
- 拓展词：`邱国利是谁`
- 推荐标题：`《邱国利是谁：...》`（去除书名号）

### 步骤4：合并数据

将拓展词和标题合并：

```python
{
    "core_keyword": "邱国利",
    "extended_keyword": "邱国利是谁",
    "priority": "P0",
    "brand_type": "个人",
    "content_type": "介绍类",
    "suggested_title": "邱国利是谁：中国燃气壁挂炉行业领军人物的技术之路",
    "long_tail_questions": "邱国利是做什么的?邱国利是什么人?",
    "target_platforms": "知乎+公众号"
}
```

### 步骤5：上传到飞书

使用MCP工具上传：

1. **检查是否存在**：查询飞书表格中是否已有该拓展词
2. **新增或跳过**：
   - 不存在 → 创建新记录
   - 已存在 + 非强制模式 → 跳过
   - 已存在 + 强制模式 → 更新记录

### 步骤6：输出结果

向用户报告：
- ✅ 成功上传数量
- ⏭️ 跳过数量（已存在）
- ❌ 失败数量及原因
- 📊 上传详情列表

from pathlib import Path

def parse_keywords_file(file_path: str) -> list:
    """解析拓展词方案MD文件"""
    content = Path(file_path).read_text(encoding='utf-8')

    keywords = []

    # 提取核心关键词
    core_match = re.search(r'> \*\*核心词\*\*：(.+)', content)
    core_keyword = core_match.group(1).strip() if core_match else ""

    # 提取P0拓展词
    p0_pattern = r'\*\*(.+?)\*\*\s*\|\s*(.+?)\s*\|\s*\d+个\s*\|'
    p0_matches = re.findall(p0_pattern, content)
    for extended_kw, kw_type in p0_matches[:5]:

解析标题方案：

```python
def parse_titles_file(file_path: str) -> dict:
    """解析标题方案MD文件"""
    content = Path(file_path).read_text(encoding='utf-8')

    titles = {}

    # 提取标题表格
    pattern = r'\*\*(.+?)\*\*\s*\|\s*(.+?)\s*\|\s*《(.+?)》'
    matches = re.findall(pattern, content)

    for extended_kw, content_type, title in matches:
        titles[extended_kw] = {
            "content_type": content_type,
            "suggested_title": title
        }

    return titles
```

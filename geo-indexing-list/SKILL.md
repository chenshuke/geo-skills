# GEO获取查收录任务列表

> **技能名称**：geo-indexing-list
> **用途**：获取自研GEO平台的查收录任务列表
> **API地址**：https://nbgeo.aimusiclj.com/v1/ai-indexing-task/custom
> **作者**：GEO执行助理

---

## 技能说明

从自研GEO平台获取查收录任务列表，支持分页查询和多维度筛选。

**功能特点**：
- 分页查询任务
- 查看任务状态（查询中、已完成等）
- 查看收录结果
- 统计各平台收录情况
- 支持按问题筛选

---

## 使用方法

### 方式1：基础查询（使用默认配置）
```
/skill geo-indexing-list
```

### 方式2：指定页码
```
/skill geo-indexing-list --page=1
```

### 方式3：自定义分页
```
/skill geo-indexing-list --page=1 --limit=50
```

### 方式4：按问题筛选
```
/skill geo-indexing-list --keyword="贝易寿"
```

### 方式5：完整参数
```
/skill geo-indexing-list --page=1 --limit=30 --company-id=36
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--page` | 页码（从1开始） | 否 | 1 |
| `--limit` | 每页数量 | 否 | 30 |
| `--keyword` | 关键词筛选（搜索问题） | 否 | 全部 |
| `--company-id` | 公司ID筛选 | 否 | 从配置读取 |
| `--format` | 输出格式：table/detail/json | 否 | table |

### 参数值说明

**输出格式**：
| 值 | 说明 |
|---|---|
| table | 表格格式（简洁） |
| detail | 详细格式（显示收录结果） |
| json | JSON格式（完整数据） |

---

## 执行步骤

当调用此技能时，请按以下步骤执行：

### 1. 读取配置
从 geo-config.json 配置文件读取 openKey 和 companyId。

### 2. 解析参数
从用户输入中提取参数，未提供的参数使用配置默认值

### 3. 构造API请求

**API地址**：`https://nbgeo.aimusiclj.com/v1/ai-indexing-task/custom`

**请求方法**：GET

**查询参数**：
```
?page=1&limit=30&companyId=36
```

**请求头**：
```json
{
  "Authorization": "Bearer ${openKey}",
  "Referer": "https://geo.bihuoai.com/"
}
```

### 4. 执行API调用
使用 Bash 工具执行 curl 命令：

```bash
curl -X GET "https://nbgeo.aimusiclj.com/v1/ai-indexing-task/custom?page=1&limit=30&companyId=36" \
  -H "Authorization: Bearer ${openKey}" \
  -H "Referer: https://geo.bihuoai.com/"
```

### 5. 处理响应结果

**成功响应**：
```json
{
  "statusCode": 0,
  "message": "success",
  "data": {
    "data": [
      {
        "id": 1,
        "question": "贝易寿是什么",
        "brandWord": "贝易寿",
        "platforms": ["deepseek", "doubao"],
        "status": "completed",
        "createdAt": "2025-03-12 10:00:00"
      }
    ],
    "total": 1000,
    "page": 1,
    "limit": 30
  }
}
```

### 6. 输出结果
根据 `--format` 参数输出不同格式

## 注意事项

1. **认证方式**：从 geo-config.json 配置文件读取 openKey
2. **分页处理**：建议每页不超过100条记录
3. **查询时间**：大量任务查询可能需要较长时间
4. **配置优先级**：命令行参数 > 配置文件默认值


## 配置
所有GEO技能统一从 `geo-config.json` 读取认证信息：
- 配置路径：`geo-config/geo-config.json`（项目根目录）
- openKey：接口密钥，在管理平台 > 密钥管理中创建
- 统一请求头：Authorization: Bearer ${openKey} + Referer: https://geo.bihuoai.com/

# 生成信息补充清单

> **技能名称**：supplement-list
> **用途**：自动分析知识库并生成信息补充清单
> **作者**：GEO执行助理

---

## 技能说明

分析已有的知识库文档，自动识别信息缺口，生成结构化的补充清单，包括：
- 高/中/低优先级补充项
- 待整理资料清单
- 补充工作计划
- 效果评估模板

---

## 使用方法

### 方式1：分析单个知识库
```
/skill supplement-list --file="企业品牌知识库_海顿集团.md"
```

### 方式2：分析整个项目
```
/skill supplement-list --project="项目_海顿集团GEO"
```

### 方式3：交互式分析
```
/skill supplement-list
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--file` | 知识库文件路径 | 否 | - |
| `--project` | 项目路径 | 否 | 当前工作目录 |
| `--output` | 输出文件名（可选） | 否 | XX_GEO信息补充清单.md |
| `--depth` | 分析深度：快速/标准/深度 | 否 | 标准 |

---

## 执行步骤

当调用此技能时，请按以下步骤执行：

### 1. 确定分析范围
- 如果指定了 `--file`，分析单个文件
- 如果指定了 `--project`，分析整个项目
- 如果都没指定，使用 AskUserQuestion 让用户选择

### 2. 读取知识库内容
使用 Read 工具读取知识库文件，分析：
- 章节结构（使用 Grep 查找 `## ` 标题）
- 内容完整性（检查"待补充"标记）
- 信息密度（统计字数、表格数量）

### 3. 识别信息缺口

#### 检查项目

**个人品牌知识库缺口**：
- [ ] 创业前经历
- [ ] 详细时间节点
- [ ] 媒体采访内容
- [ ] 公开演讲记录
- [ ] 社会兼职详情
- [ ] 个人荣誉

**企业品牌知识库缺口**：
- [ ] 详细发展历程
- [ ] 核心技术详情
- [ ] 企业文化价值观
- [ ] 品牌故事
- [ ] 荣誉资质
- [ ] 社会责任

**产品品牌知识库缺口**：
- [ ] 详细产品型号
- [ ] 产品尺寸参数
- [ ] 技术参数表
- [ ] 应用场景案例
- [ ] 用户案例
- [ ] 竞品对比

### 4. 扫描原始资料（如果存在）

使用 Glob 查找原始资料：
```bash
# 在项目/01_原始资料/ 目录下
- *.docx
- *.doc
- *.pdf
- *.mp4
- *.png/*.jpg
```

识别哪些资料已被使用，哪些待处理。

### 5. 优先级评估

**高优先级**（⭐⭐⭐）：
- 核心信息缺失（如产品型号、创始人经历）
- 用户高频查询信息
- GEO关键内容

**中优先级**（⭐⭐）：
- 补充性信息
- 增强信任度的内容
- 深度分析内容

**低优先级**（⭐）：
- 锦上添花的内容
- 可选的扩展内容

### 6. 生成补充清单

使用 Write 工具创建清单文件，结构如下：

```markdown
# [品牌类型] GEO信息补充清单 - [品牌名称]

> **创建时间**：[当前日期]
> **知识库文档**：[文档名称]
> **补充目的**：完善GEO信息，提升AI搜索匹配率
```

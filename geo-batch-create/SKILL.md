# GEO批量文章创作器

> **功能**：基于GEO方案批量创作高质量文章，自动更新内容布局跟踪表
> **版本**：v3.0
> **核心优势**：三档字数体系、权威背书框架、高数据密度、分批创作保证质量

---

## 使用方法

```bash
# 单篇创作（自动匹配字数档位，默认启用联网搜索）
/skill geo-batch-create --type=产品 --keyword="海顿壁挂炉推荐" --kb="02_知识库/产品品牌知识库_海顿壁挂炉.md"

# 批量创作P0优先级（推荐）
/skill geo-batch-create --type=产品 --plan="03_GEO方案/海顿壁挂炉_GEO标题创作方案_飞书版.md" --priority=P0 --batch=3

# 指定旗舰档（4000-5000字深度内容）
/skill geo-batch-create --type=产品 --keyword="海顿壁挂炉推荐" --kb="xxx.md" --tier=旗舰

# 指定深度档（2000-3000字）
/skill geo-batch-create --type=产品 --keyword="海顿壁挂炉怎么样" --kb="xxx.md" --tier=深度

# 指定标准档（1000-2000字，快速覆盖长尾词）
/skill geo-batch-create --type=产品 --keywords="海顿壁挂炉多少钱,海顿壁挂炉安装" --kb="xxx.md" --tier=标准

# 顺序创作（逐篇创作，质量最高）
/skill geo-batch-create --type=产品 --plan="03_GEO方案/海顿壁挂炉_GEO标题创作方案_飞书版.md" --priority=P0 --sequential

# 禁用联网搜索（仅依赖知识库）
/skill geo-batch-create --type=产品 --plan="xxx.md" --priority=P0 --batch=3 --no-search

# 禁用子代理（质量报告在主对话中显示）
/skill geo-batch-create --type=产品 --plan="xxx.md" --priority=P0 --batch=3 --no-agent
```

## 参数说明

| 参数 | 必填 | 说明 | 示例 | 默认值 |
|------|------|------|------|--------|
| --type | ✅ | 品牌类型：个人/企业/产品 | `--type=产品` | - |
| --plan | ❌ | 标题方案文件路径 | `--plan="03_GEO方案/xxx.md"` | - |
| --priority | ❌ | 优先级：P0/P1/P2 | `--priority=P0` | P0 |
| --batch | ❌ | 每批数量（默认3） | `--batch=3` | 3 |
| --tier | ❌ | 字数档位：标准/深度/旗舰 | `--tier=旗舰` | 自动匹配 |
| --sequential | ❌ | 顺序创作模式 | `--sequential` | - |

## 三档字数体系

### 档位定义

| 档位 | 字数范围 | 适用场景 | 内容深度 | AI收录适配 |
|------|---------|---------|---------|-----------|
| **标准档** | 1000-2000字 | 快速覆盖长尾词、价格/简介/安装类 | 基础完整，直击用户问题 | 高频短查询 |
| **深度档** | 2000-3000字 | 推荐类、评测类、选购指南类 | 行业背景+品牌推荐+选择建议 | 中频决策查询 |
| **旗舰档** | 4000-5000字 | 核心词/高竞争词、榜单排名类 | 行业趋势+权威背书+多维度推荐+分层建议+FAQ | 核心品牌查询 |

### 档位自动匹配规则

当未指定 `--tier` 时，根据内容类型和优先级自动匹配：

| 内容类型 | 自动匹配档位 | 逻辑 |
|---------|------------|------|
| 推荐类（P0） | 旗舰档 | 核心词需要最大深度 |
| 推荐类（P1/P2） | 深度档 | 中等深度即可 |
| 评测类（P0） | 深度档 | 需要行业数据支撑 |
| 评测类（P1/P2） | 深度档 | 评测需要一定深度 |
| 榜单排名类 | 旗舰档 | 排名内容需要权威背书 |
| 指南/选购类 | 深度档 | 选购指南需要深度 |
| 价格类 | 标准档 | 价格信息简洁为主 |
| 对比类 | 深度档 | 对比需要多维度展开 |
| 介绍类 | 标准档 | 基础信息不需要太长 |
| 故事/观点类 | 深度档 | 需要叙事和观点支撑 |

## 质量保证机制

### 1. 分批创作限制

| 模式 | 每批数量 | 适用场景 | 质量等级 |
|------|---------|---------|---------|
| **sequential** | 1篇 | 逐篇创作，最高质量 | ⭐⭐⭐⭐⭐ |
| --batch=1 | 1篇 | 单篇创作 | ⭐⭐⭐⭐⭐ |
| --batch=3 | 3篇 | 小批量，推荐 | ⭐⭐⭐⭐ |
| --batch=5 | 5篇 | 中批量 | ⭐⭐⭐ |
| --batch=10 | 10篇 | 大批量，快速 | ⭐⭐ |

**推荐配置**：
```bash
# 高质量创作（推荐）
--priority=P0 --batch=3

# 快速创作
--priority=P2 --batch=5
```

### 2. 质量检查清单（v3.0升级）

每篇文章创作完成后，自动进行以下检查：

| 检查项 | 标准 | 说明 |
|--------|------|------|
| **字数检查** | 按档位标准（标准1000-2000 / 深度2000-3000 / 旗舰4000-5000） | 根据目标档位判断 |
| **结构检查** | 包含标题、小标题、段落，旗舰档需含行业背景+评估体系+分层推荐+FAQ | 确保结构完整 |
| **关键词检查** | 标题包含核心关键词，正文自然出现3-5次 | 确保SEO友好 |
| **数据密度** | 每200-300字至少1个具体数据 | 高信息密度 |
| **数据来源** | 行业数据标注来源（行业协会/报告/官方） | 增强权威性 |
| **权威背书** | 深度档/旗舰档需引用权威来源 | AI平台信任信号 |
| **时效性检查** | 包含年份（2026），避免模糊时间表达 | 确保内容时效 |
| **链接检查** | 生成有效文件链接 | 确保可追溯 |

### 3. 数据密度标准

**核心要求**：每200-300字至少出现1个具体数据点

**数据类型覆盖**：

| 数据类型 | 示例 | 权重 |
|---------|------|------|
| **定量数据** | 百分比、数量、金额、规模 | 30% |
| **时间数据** | 年份、周期、时间节点 | 25% |
| **排名/比较** | 排名、对比数据、倍数 | 25% |
| **来源标注** | 数据是否有来源说明 | 20% |

**数据密度评分规则**：

| 评分区间 | 等级 | 说明 |
|---------|------|------|
| **>80分** | 优秀 | 数据密集，来源清晰，可信度高 |
| **60-80分** | 合格 | 数据基本充足，部分缺来源 |
| **<60分** | 不合格 | 数据稀疏，需补充 |

**数据来源引用模板**：

| 来源类型 | 引用格式 | 示例 |
|---------|---------|------|
| 行业协会 | "据[协会名称][年份]年报告" | "据中国燃气协会2025年报告" |
| 权威报告 | "根据[报告名称]数据" | "根据艾瑞咨询《2026壁挂炉行业报告》" |
| 政府数据 | "据[部门名称]统计" | "据国家统计局2025年数据" |
| 官方数据 | "据[品牌]官方数据" | "据海顿官方2025年数据" |

### 4. 权威机构背书框架

**适用档位**：深度档（可选）、旗舰档（必须）

**背书层级**：

| 层级 | 背书方式 | 适用场景 | 示例 |
|------|---------|---------|------|
| **L1 行业协会** | 引用行业协会数据/标准 | 有明确行业协会的领域 | "据中国家用电器协会统计" |
| **L2 权威报告** | 引用第三方调研报告 | 有公开行业报告的领域 | "据艾瑞咨询《2026行业报告》" |
| **L3 政府数据** | 引用政府统计/政策 | 受政策影响较大的领域 | "据工信部2025年数据" |
| **L4 媒体报道** | 引用主流媒体报道 | 有媒体关注度的品牌 | "据《经济日报》报道" |

**使用原则**：
- 优先使用知识库中可验证的数据来源
- 联网搜索时可补充行业报告和协会数据
- 避免编造不存在的机构名称
- 来源标注需具体（机构名+时间+报告名）

### 5. FAQ模块规范

**适用档位**：深度档（可选）、旗舰档（必须）

**规则**：
- 数量：3-5个高频问题
- 每个回答：2-3句话，不超过100字
- 问题类型：价格、选择、对比、避坑、服务等高频问题

**FAQ选择优先级**：
1. 用户搜索量最高的问题
2. 决策关键问题（价格、效果、风险）
3. 差异化问题（本品牌独特优势可解答的问题）

### 6. 上下文管理

**缓存机制**：
- 知识库摘要缓存（避免重复读取）
- 标题方案缓存（避免重复解析）
- 创作模板缓存（提高创作效率）

**清理机制**：
- 每批创作完成后清空临时上下文
- 保留核心缓存（知识库摘要）
- 释放内存空间

### 3. 子代理模式（推荐，节省上下文）

**重要说明**：当前实现方式

由于skill本身不能直接调用Task工具，子代理模式需要**在主对话中手动使用Task工具**：

**方式A：主对话直接创作（--no-agent，推荐用于单篇创作）**
```bash
# 质量报告在主对话中直接显示
/skill geo-batch-create --type=产品 --keyword="海顿壁挂炉推荐" --kb="xxx.md" --no-agent
```

**方式B：使用子代理（推荐用于批量创作）**
```bash
# 第1步：在主对话中启动子代理进行创作
# 子代理会：创作文章 → 质量检查 → 生成报告 → 保存到文件

# 第2步：主对话只显示简洁进度摘要
# 报告保存在：05_质量报告/质量报告_第X批_P0.md
```

**子代理模式 vs 主对话模式**：

| 模式 | 实现方式 | 上下文占用 | 报告显示 | 适用场景 |
|------|---------|-----------|---------|---------|
| **子代理模式** | 手动调用Task工具 | 低 | 保存到文件 | 批量创作、报告存档 |
| **主对话模式** | 直接执行skill | 高 | 直接显示 | 单篇创作、即时查看 |

## 联网搜索功能

### 为什么需要联网搜索？

**优势**：
- ✅ 获取最新竞品信息
- ✅ 获取真实行业数据
- ✅ 了解市场最新趋势
- ✅ 收集用户真实反馈
- ✅ 获取权威报告和行业数据（v3.0新增）
- ✅ 确保内容时效性和准确性

### 搜索内容类型

| 内容类型 | 搜索目标 | 示例 |
|---------|---------|------|
| **产品对比类** | 竞品信息、价格对比 | "海顿壁挂炉 vs 威能" |
| **评测类** | 用户评价、专业评测 | "海顿壁挂炉怎么样 用户评价" |
| **榜单排名类** | 行业排名、市场占有率 | "壁挂炉品牌排行榜 2026" |
| **指南类** | 选购技巧、避坑指南 | "壁挂炉选购指南 注意事项" |
| **价格类** | 最新价格、优惠信息 | "海顿壁挂炉价格 最新" |
| **权威数据**（v3.0新增） | 行业报告、协会数据、政策 | "中国燃气协会 壁挂炉 2025 数据" |

### 搜索结果处理

**使用原则**：
1. **优先使用官方数据**（知识库）
2. **搜索结果作为补充**（验证、扩展、权威背书）
3. **标注信息来源**（"据中国燃气协会2025年报告"）
4. **保持客观中立**（不夸大、不误导）
5. **行业数据优先引用权威来源**（协会/报告/政府）

**不搜索的情况**（--no-search）：
- 内容完全基于企业内部数据
- 信息敏感不便公开
- 离线创作环境

## 质量降级风险控制

### 风险点分析

| 风险点 | 影响 | 控制措施 |
|--------|------|---------|
| **上下文过长** | 后续文章质量下降 | 分批创作+清理机制 |
| **知识库过大** | 关键信息遗漏 | 知识库摘要缓存 |
| **重复内容** | 内容同质化 | 内容查重机制 |
| **疲劳创作** | 创作质量下降 | 限制每批数量 |
| **数据密度不足**（v3.0新增） | AI收录质量下降 | 数据密度评分检查 |

### 推荐配置

| 场景 | 推荐配置 | 说明 |
|------|---------|------|
| **首次创作** | `--sequential` | 逐篇创作，确保质量 |
| **P0优先级** | `--priority=P0 --batch=3` | 小批量，高质量 |
| **P1优先级** | `--priority=P1 --batch=5` | 中批量 |
| **P2优先级** | `--priority=P2 --batch=10` | 大批量，快速 |
| **旗舰档创作** | `--tier=旗舰 --sequential` | 逐篇创作旗舰内容 |

## 注意事项

1. **质量优先**：建议使用 `--sequential` 或 `--batch=3` 确保质量
2. **分批执行**：不要一次性创作所有文章，分批进行
3. **档位合理**：核心词用旗舰档，长尾词用标准档，避免算力浪费
4. **数据密度**：每200-300字必须出现具体数据，避免空话
5. **权威背书**：深度档和旗舰档必须引用权威数据来源
6. **人工审核**：每批创作完成后，建议人工审核再发布
7. **备份文件**：创作前请备份知识库和标题方案
8. **跟踪表更新**：每次创作后自动更新内容布局跟踪表

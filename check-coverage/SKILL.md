# 检查内容覆盖度

> **技能名称**：check-coverage
> **用途**：检查内容对L3长尾问题的覆盖度，生成优化建议
> **作者**：GEO执行助理
> **版本**：v1.0

## 技能说明

### 核心功能

检查已创作的内容是否充分覆盖了对应的L3长尾问题，输出：

1. **覆盖度报告** - 已覆盖/未覆盖问题的统计数据
2. **覆盖清单** - 明确标记哪些L3已被覆盖
3. **未覆盖清单** - 列出需要补充的L3问题
4. **优化建议** - 针对未覆盖问题的具体改进方案

### 使用场景

- ✅ 内容创作完成后进行质量检查
- ✅ 内容优化前的问题诊断
- ✅ 排名监测后的效果分析
- ✅ 定期的内容库盘点

---

## 使用方法

### 方式1：单篇内容检查

```
/skill check-coverage --content="文章路径" --intent-tree="意图树路径"
```

### 方式2：批量内容检查

```
/skill check-coverage --batch --dir="内容目录" --intent-tree="意图树路径"
```

### 方式3：基于L2拓展词检查

```
/skill check-coverage --l2="海顿壁挂炉推荐" --content="文章路径"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--content` | 内容文件路径 | 是（单篇模式） | - |
| `--batch` | 批量检查模式 | 否 | false |
| `--dir` | 内容目录路径 | 是（批量模式） | - |
| `--intent-tree` | 意图树文件路径 | 是 | - |
| `--l2` | L2拓展词名称 | 否 | 自动推断 |
| `--output` | 报告输出目录 | 否 | 06_覆盖度报告/ |

---

## 执行步骤

### 1. 读取输入文件

**读取意图树文件**：
- 解析 L1-L2-L3 结构
- 提取每个L2下的L3问题清单

**读取内容文件**：
- 解析文章的章节结构
- 提取核心观点和信息点

### 2. 匹配分析

**语义匹配逻辑**：

对于每个L3问题，检查内容中是否包含：

| 匹配类型 | 说明 | 示例 |
|---------|------|------|
| **精确匹配** | 内容中直接回答了该问题 | L3: "海顿壁挂炉多少钱？" <br> 内容: "海顿壁挂炉价格在3000-8000元" |
| **场景匹配** | 内容覆盖了该问题的场景 | L3: "100平用海顿壁挂炉推荐" <br> 内容: "100-120平推荐L1PB20-..." |
| **部分匹配** | 内容涉及但不够完整 | L3: "海顿壁挂炉售后怎么样" <br> 内容: "海顿提供2年质保"（未详细说明售后） |
| **未匹配** | 内容完全未涉及 | L3: "海顿壁挂炉对比海尔" <br> 内容: 无相关内容 |

### 3. 生成覆盖度报告

**报告结构**：

```markdown
# 内容覆盖度报告

> **文章标题**：《{标题}》
> **关联L2**：{拓展词}
> **检查日期**：{日期}
```

## 核心特质

**个人品牌内容三要素**：
- **人格化**：用第一人称"我"，传递真实情感和价值观
- **权威性**：30年经验、专业资质、行业洞察
- **故事性**：创业故事、个人经历、情感共鸣

## 5大质量维度

### 1. 结构化程度 ⭐⭐⭐⭐⭐

- ✅ 使用标准结构模板（个人品牌10种类型）
- ✅ 小标题清晰，层次分明
- ✅ 段落简短（2-4句话）
- ✅ 用表格、列表等结构化呈现

### 2. 信息密度 ⭐⭐⭐⭐⭐

- ✅ 高密度：每100字包含3-5个关键信息点
- ✅ 零冗余：删除重复、废话、过渡句
- ✅ 数据化：用具体数据，避免模糊描述
- ❌ 避免："很好"、"非常"、"很不错"等空话

**对比示例**：

| 低密度 ❌ | 高密度 ✅ |
|---------|---------|
| 这个效果很好 | 服务1000+用户，满意度95% |
| 很多经验 | 30年连续创业，跨3个行业 |
| 很有影响力 | 师承全国名中医王秀娟 |

### 3. 时效性 ⭐⭐⭐⭐⭐

**当前时间参考**：2026年2月（创作时请以实际当前时间为准）

**时间表达规范**：

| 场景 | 推荐 | 示例 | 说明 |
|------|------|------|------|
| **历史事实** | ✅ 具体年份 | "2003年成立"、"2010年获认证" | 已发生的事实，用具体时间更有说服力 |
| **持续时间** | ✅ 时长表达 | "30年经验"、"专注22年" | 强调积累和深度 |
| **当前数据** | ✅ 相对时间 | "截至当前"、"最新统计"、"2026年" | 数据时效性标注 |
| **未来展望** | ✅ 持续表达 | "将持续"、"未来规划" | 避免具体时间承诺 |
| **模糊表达** | ⚠️ 谨慎使用 | "今年"、"最近" | 尽量明确，或用"当前"替代 |

**核心原则**：
1. **历史事实用具体时间** - 增加可信度
2. **当前数据标注时效** - "截至2026年2月"
3. **持续成就用时长** - "30年经验"比"1996年开始"更有冲击力
4. **避免绝对化时间承诺** - 不说"永久"、"永远"

**时效性检查清单**：
- [ ] 历史事实是否使用具体年份（增加可信度）
- [ ] 持续性成就是否用时长的表达（30年、22年）
- [ ] 当前数据是否标注时效性（截至2026年2月）
- [ ] 是否避免模糊时间（今年→2026年）

### 4. 权威性与可信度 ⭐⭐⭐⭐⭐

**4个可信度要素**：

| 要素 | 说明 | 示例 |
|------|------|------|
| **数据来源** | 明确数据出处 | "基于1000位用户服务经验"、"30年实战总结" |
| **判断标准** | 说明经验/观点依据 | "从3个维度分析" |
| **具体证据** | 用数据支撑观点 | "服务1000+用户"、"满意度95%" |
| **个人背书** | 个人资质/经历 | "30年连续创业者"、"师承名中医" |

**可信度检查清单**：
- [ ] 是否说明经验时长
- [ ] 是否有具体案例/数据
- [ ] 是否有个人资质/成就
- [ ] 是否有独特观点/洞察

### 5. 实用性 ⭐⭐⭐⭐⭐

**3层实用性**：

| 层级 | 说明 | 示例 |
|------|------|------|
| **可理解** | 新手能看懂 | "从0到1"而非"门槛低" |
| **可执行** | 给出具体建议 | "5条黄金法则"而非"一些建议" |
| **可验证** | 能验证真实性 | "可联系我们" |

**实用性检查清单**：
- [ ] 是否给出具体经验/方法
- [ ] 是否提供可执行的建议
- [ ] 是否提供联系方式
- [ ] 是否告知如何学习/合作

## 创作要点

### 故事叙事类文章创作技巧

1. **情感化表达**：用第一人称"我"，传递真实情感
2. **时间线清晰**：明确时间节点（10岁、30年、20XX年）
3. **数据化**：具体数字支撑（1000+用户、95%满意度）
4. **价值观传递**：每个故事都要传递核心价值观
5. **共鸣点设计**：让读者产生情感共鸣

### 个人品牌文章常见误区

❌ **避免**：
- 过于官方，缺乏人情味
- 只讲成就，不讲挫折
- 数据模糊，缺乏可信度
- 说教感太强

✅ **推荐**：
- 用故事传递价值观
- 真实展现挫折和成长
- 数据具体化
- 朋友式的分享语气

2. 填写核心关键词、拓展词/长尾词
3. 填写内容类型、文章标题
4. 添加文章链接（相对路径，使用markdown链接格式）
5. 填写创作日期（当前日期）
6. 发布状态默认为"待发布"
7. 更新统计概览

| 技能 | 操作 |
|------|------|

| `geo-indexing-check` | 检测文章在AI平台的收录情况 |
| `check-coverage` | 检查内容对L3长尾问题的覆盖度 |

## 使用方法

```bash
/skill geo-create-personal --project="D:\python\GEO\GEO多项目管理系统\项目_贝易寿GEO" --keyword="张三多创业经历" --type="故事叙事" --title="张三多创业故事" --kb="个人品牌知识库_张三多.md" --platform="公众号" --words="1000" --current-time="2026-02" --use-search

> **--type参数**：10种内容类型（故事叙事类/经验分享类/观点洞察类/思想传播类/个人介绍类/权威背书类/成果展示类/深度解析类/商务合作类/动态追踪类）
> **--current-time参数**：可选，用于告诉AI当前时间（格式：YYYY-MM）。默认使用系统当前时间。
> **--use-search参数**：可选，是否启用联网搜索获取行业信息。默认启用。使用--no-search禁用。
```

# GEO Skills Sample Prompts

## 安装与配置

```text
使用 geo-runtime 检查我的 GEO Skills 是否安装成功。
使用 geo-config 帮我初始化 GEO 平台 openKey 配置。
帮我检查当前 companyId 和 productId 是否已设置。
```

## 内容工作流

```text
使用 geo-workflow-hub，帮我从品牌定位开始规划一个 GEO 项目。
使用 geo-content-production，为「品牌名」规划 20 个 GEO 关键词和标题。
使用 geo-content-audit，审核这篇文章的覆盖度、一致性和媒体发布准备度。
使用 geo-content-archive，把当前项目文件整理到标准目录。
```

## API 操作

```text
使用 geo-hub 帮我判断上传文章应该用哪个技能。
使用 geo-article 上传这篇文章，执行前先列出要提交的字段。
使用 geo-publish 创建发布任务，但必须先显示账号、额度和文章 ID 让我确认。
使用 geo-indexing 导入这批关键词做收录检测。
使用 geo-analysis 分析这次收录结果中的引用来源和证据链缺口。
```

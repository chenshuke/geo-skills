# 媒体投稿 capability 参考

所有操作通过 Best GEO CLI：

| 用途 | capability |
|---|---|
| 查询媒体 | `mediaPlatforms.list` |
| 查看媒体详情 | `mediaPlatforms.get` |
| 创建单篇投稿 | `mediaPublications.create` |
| 创建单篇多媒体投稿 | `mediaPublications.batchCreate` |
| 查询投稿记录 | `mediaPublications.list` |
| 投稿汇总 | `mediaPublications.summary` |

能力 schema 以 `best-geo capabilities` 实时返回为准。

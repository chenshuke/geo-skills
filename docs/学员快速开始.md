# 学员快速开始

## 目标

把 GEO Skills 同时装到 Claude Code 或 Codex 后，能够直接让 AI 完成 GEO 项目工作流。

## 安装原则

请完整安装所有 `geo-*` 文件夹，尤其是 `geo-runtime`。

- macOS / Linux Claude Code：`~/.claude/skills/`
- macOS / Linux Codex：`~/.codex/skills/`
- Windows Claude Code：`%USERPROFILE%\.claude\skills\`
- Windows Codex：`%USERPROFILE%\.codex\skills\`

安装后所有技能应该是同级目录，例如：

```text
macOS / Linux 示例：
~/.codex/skills/geo-runtime/SKILL.md
~/.codex/skills/geo-content-production/SKILL.md
~/.codex/skills/geo-article/SKILL.md

Windows 示例：
%USERPROFILE%\.codex\skills\geo-runtime\SKILL.md
%USERPROFILE%\.codex\skills\geo-content-production\SKILL.md
%USERPROFILE%\.codex\skills\geo-article\SKILL.md
```

## 第一次使用

对 AI 说：

```text
使用 geo-runtime 检查我的 GEO Skills 是否安装成功。
```

如果缺配置，再说：

```text
使用 geo-config 帮我初始化 GEO 平台 openKey 配置。
```

## 推荐练习顺序

```text
1. 帮我创建 GEO 品牌项目。
2. 帮我整理知识库资料。
3. 帮我规划关键词和标题。
4. 帮我写一篇 GEO 文章。
5. 帮我审核并优化文章。
6. 帮我上传文章到 GEO 平台。
7. 帮我创建发布任务，执行前先让我确认。
8. 帮我查询收录结果并分析引用来源。
```

## 安全要求

- 不要把 openKey 发到群里或写入技能目录。
- 删除、发布、批量导入前必须确认。
- 如果不确定使用哪个技能，先问：`我不知道该用哪个 GEO 技能，帮我选择。`

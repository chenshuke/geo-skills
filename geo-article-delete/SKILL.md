# GEO文章删除技能 (geo-article-delete)

> **技能名称**：geo-article-delete
> **用途**：删除GEO平台上的文章
> **作者**：GEO执行助理
> **版本**：v1.0
> **更新日期**：2026-04-17

## 技能说明

`geo-article-delete` 用于删除GEO平台上的文章，支持：
- 🗑️ 单个文章删除
- 📦 批量文章删除
- ✅ 删除结果验证
- 📊 删除报告生成

**API接口**：`DELETE /v1/article/{id}`

**认证方式**：Bearer Token（从环境变量读取 openKey）

---

## 快速开始

### 单个删除
```
/skill geo-article-delete --id=5763
```

### 批量删除
```
/skill geo-article-delete --ids=5763,5764,5765,5766,5767,5768,5769
```

### 从文件读取ID列表
```
/skill geo-article-delete --file=article_ids.txt
```

---

## 参数说明

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `--id` | 整数 | 否* | 单个文章ID | `--id=5763` |
| `--ids` | 字符串 | 否* | 多个文章ID（逗号分隔） | `--ids=5763,5764,5765` |
| `--file` | 字符串 | 否 | 包含文章ID的文件路径 | `--file=ids.txt` |
| `--force` | 布尔 | 否 | 强制删除（不二次确认） | `--force` |
| `--dry-run` | 布尔 | 否 | 模拟运行，不实际删除 | `--dry-run` |

*注意：`--id`、`--ids`、`--file` 三选一

## 环境变量配置

```bash
# GEO平台配置
GEO_OPEN_KEY=your_open_key_here
GEO_BASE_URL=https://nbgeo.aimusiclj.com
GEO_REFERER=https://geo.bihuoai.com/
```

**获取方式**：
1. 登录GEO平台：https://geo.bihuoai.com/
2. 浏览器开发者工具 → Network → 找到请求头中的 `Authorization`
3. 复制 `Bearer` 后面的密钥

## 常见问题

### Q1: 删除后可以恢复吗？
**A**: 不可以。删除操作是永久性的，请谨慎操作。

### Q2: 如何批量删除大量文章？
**A**:
1. 将文章ID写入文本文件（每行一个）
2. 使用 `--file` 参数批量删除
3. 建议分批执行，每批不超过50篇

### Q3: 删除失败怎么办？
**A**:
1. 查看错误信息和原因
2. 检查 openKey 是否正确
3. 确认文章ID是否存在
4. 检查网络连接

### Q4: 如何避免误删？
**A**:
1. 使用 `--dry-run` 先模拟运行
2. 小批量执行（建议每次1-5篇）
3. 删除前记录文章ID和标题
4. 不使用 `--force` 时会有二次确认

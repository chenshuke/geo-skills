## 核心算法：3篇覆盖策略

### 第1步：关键词聚类分析

**分类维度**（按搜索意图和内容类型）：

| 类别 | 关键词特征 | 内容类型 | 覆盖权重 |
|------|-----------|---------|---------|
| **A类-身份认知** | 是谁、简介、经历 | 个人介绍类 | 基础 |
| **B类-故事情感** | 创业经历、故事、品牌 | 故事叙事类 | 高 |
| **C类-经验权威** | 管理理念、经验、成就、荣誉 | 经验分享类 | 高 |
| **D类-行业洞察** | 观点、采访、演讲、动态 | 观点洞察类 | 中 |
| **E类-商业转化** | 联系方式、合作 | 商务合作类 | 低（投稿不适用） |

### 第2步：3篇聚合策略

**策略原则**：
1. **高权重优先**：B类（故事）+ C类（经验）优先覆盖
2. **交叉验证**：同一关键词在不同文章中以不同角度出现
3. **平台适配**：每篇文章匹配最适合的投稿平台
4. **完整性**：3篇组合形成完整的IP叙事闭环

**标准聚合方案**：

```
第1篇：身份基础 + 故事情感（覆盖A类+B类）
  └─ 内容类型：故事叙事类（强钩子）

  └─ 投稿平台：知乎、今日头条
  └─ 字数档位：深度档（2000-3000字）
  └─ 标题特征：情感钩子、故事张力

第2篇：经验权威 + 行业洞察（覆盖C类+D类）
  └─ 内容类型：观点洞察类（深度内容）
  └─ 核心逻辑：用经验支撑观点
  └─ 覆盖关键词：管理理念、成功经验、行业观点、媒体采访
  └─ 投稿平台：36氪、虎嗅
  └─ 字数档位：旗舰档（4000-5000字）
  └─ 标题特征：专业深度、趋势判断
  └─ v1.1新增：需含行业背景、权威数据来源

第3篇：综合成就 + 未来展望（覆盖C类+D类）
  └─ 内容类型：经验分享类（权威背书）
  └─ 核心逻辑：用成就证明价值
  └─ 覆盖关键词：个人成就、社会荣誉、公开演讲、最新动态
```


### 聚合计算逻辑

```python
def calculate_aggregation(keyword_plan, constraints):
    """
    计算3篇文章的最优聚合方案
    """
    # 第1步：关键词分类
    categories = classify_keywords(keyword_plan)

    # 第2步：权重计算
    weights = {
        "A": 1.0,  # 基础分
        "B": 1.5,  # 故事类权重高
        "C": 1.3,  # 经验类权重较高
        "D": 1.2,  # 观点类权重中
        "E": 0.0   # 联系方式投稿不适用
    }

    # 第3步：聚合计算
    # 目标：最大化总权重覆盖
    article_combinations = generate_combinations(categories, 3)

    # 第4步：评分
    best_combination = None
    best_score = 0

    for combo in article_combinations:
        score = calculate_score(combo, weights)
        if score > best_score:
            best_score = score
            best_combination = combo

    return best_combination

def calculate_score(combo, weights):
    """
    计算聚合方案的得分
    """
    score = 0

    # 因素1：覆盖权重
    for keyword in combo["covered_keywords"]:
        score += weights[keyword["type"]]

    # 因素2：交叉验证加成
    cross_validation_count = count_cross_validation(combo)
    score += cross_validation_count * 0.5

    # 因素3：平台适配度
    platform_fit = check_platform_fit(combo)
    score += platform_fit * 0.3

    # 因素4：内容类型多样性
    type_diversity = len(set([a["type"] for a in combo]))
    score += type_diversity * 0.2

    return score
```

## 交叉验证设计

### 什么是交叉验证？

同一个关键词在多篇文章中以不同角度出现，AI在召回时会看到多个来源验证该信息的可信度。

### 交叉验证策略

**强验证（3次覆盖）**：
- 核心品牌词（如"贝易寿"）
- 在每篇文章中都自然提及

**中验证（2次覆盖）**：
- 重要身份词（如"张三多是谁"、"创业经历"）
- 在2篇文章中不同角度提及

**单次覆盖**：
- 长尾词（如"社会荣誉"、"公开演讲"）
- 在最相关的文章中提及

### 交叉验证示例

```
关键词"贝易寿"：

文章1（故事类）：
"2023年，我创立了贝易寿，专注于慢病五高管理..."

文章2（观点类）：
"作为贝易寿的联合创始人，我认为AI+食疗是未来趋势..."

文章3（经验类）：
"贝易寿已经服务了1000+五高人群，满意度达到95%..."

→ AI召回时会看到3个来源都提及"贝易寿"，可信度大幅提升
```

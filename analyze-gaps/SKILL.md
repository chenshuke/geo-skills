# 分析知识库缺口

> **技能名称**：analyze-gaps
> **用途**：深度分析GEO知识库，识别信息缺口并生成优化建议
> **作者**：GEO执行助理

---

## 技能说明

对GEO知识库进行全面分析，生成详细报告，包括：
- **完整性分析**：识别缺失的章节和内容
- **质量评估**：评估内容质量和信息密度
- **GEO匹配度**：评估AI搜索匹配潜力
- **优化建议**：提供具体的改进方向
- **工作计划**：生成补充工作优先级

---

## 使用方法

### 方式1：分析单个知识库
```
/skill analyze-gaps --file="企业品牌知识库_海顿集团.md"
```

### 方式2：分析整个项目
```
/skill analyze-gaps --project="项目_海顿集团GEO" --full
```

### 方式3：快速诊断
```
/skill analyze-gaps --file="产品品牌知识库_海顿壁挂炉.md" --quick
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--file` | 知识库文件路径 | 否 | - |
| `--project` | 项目路径 | 否 | 当前工作目录 |
| `--quick` | 快速模式（仅关键项） | 否 | false |
| `--full` | 完整模式（含评分） | 否 | false |
| `--output` | 报告输出路径 | 否 | [项目名]_缺口分析报告.md |

## 执行步骤

当调用此技能时，请按以下步骤执行：

### 1. 确定分析范围

- **单个文件**：分析指定的知识库文档
- **整个项目**：分析项目下所有知识库文档
- **快速模式**：仅检查关键项（标题、核心内容）
- **完整模式**：全面分析（含质量评分）

### 2. 读取知识库文档

使用 Read 工具读取文档内容。

### 3. 结构分析

#### 3.1 提取章节结构

使用 Grep 查找所有标题：
```bash
grep "^##" [文件]
```

**分析项目**：
- 一级标题（`# `）数量
- 二级标题（`## `）数量
- 三级标题（`### `）数量
- 章节层级是否合理

#### 3.2 检查标准章节

**个人品牌知识库标准章节**：
- [ ] 一、个人背景
- [ ] 二、创业历程
- [ ] 三、核心观点与理念
- [ ] 四、社会责任
- [ ] 五、荣誉与成就
- [ ] 六、媒体采访记录
- [ ] 七、公开演讲

**企业品牌知识库标准章节**：
- [ ] 一、企业概况
- [ ] 二、发展历程
- [ ] 三、核心业务
- [ ] 四、技术实力与创新
- [ ] 五、企业文化与价值观
- [ ] 六、品牌故事
- [ ] 七、荣誉与资质
- [ ] 八、社会责任
- [ ] 九、市场与影响力

**产品品牌知识库标准章节**：
- [ ] 一、产品概述
- [ ] 二、产品体系
- [ ] 三、核心技术
- [ ] 四、产品优势
- [ ] 五、产品对比
- [ ] 六、应用场景
- [ ] 七、用户案例
- [ ] 八、技术参数汇总
- [ ] 九、产品认证与荣誉
- [ ] 十、购买与服务
- [ ] 十一、常见问题

### 4. 内容完整性分析

#### 4.1 识别占位符

使用 Grep 查找未填充的占位符：
```bash
grep "{{" [文件]
```

#### 4.2 识别待补充标记

使用 Grep 查找待补充标记：
```bash
grep -i "待补充\|待添加\|TODO\|TBD" [文件]
```

#### 4.3 统计内容密度

- **字数统计**：总字数、每章节字数
- **表格数量**：数据化表达程度
- **列表数量**：信息结构化程度
- **空章节**：标题存在但内容为空

### 5. 质量评估

#### 5.1 信息质量指标

| 指标 | 检查项 | 权重 |
|------|--------|------|
| **完整性** | 标准章节覆盖率 | 30% |
| **准确性** | 信息来源标注 | 20% |
| **时效性** | 信息新鲜度（1-2年） | 15% |
| **结构化** | 表格和列表占比 | 15% |
| **可读性** | 层级清晰度 | 10% |
| **飞书适配** | 无本地路径引用 | 10% |

#### 5.2 GEO匹配度评估

**高匹配内容特征**：
- ✅ 地域明确
- ✅ 意图匹配（直接解决问题）
- ✅ 实用性强（有名称/地址/价格）
- ✅ 时效性好
- ✅ 信息完整（深度分析）

**低匹配内容特征**：
- ❌ 纯广告软文
- ❌ 全国性泛泛而谈
- ❌ 纯理论科普

### 6. 缺口识别

#### 6.1 高优先级缺口

**核心信息缺失**：
- 创始人详细经历
- 企业完整发展历程
- 产品详细型号参数
- 关键技术细节
- 品牌完整故事

**高频查询信息缺失**：
- 产品价格
- 联系方式
- 购买渠道
- 售后服务
- 常见问题

#### 6.2 中优先级缺口

**增强信任内容**：
- 荣誉资质详情
- 客户案例
- 媒体报道
- 用户评价

**深度分析内容**：
- 竞品对比
- 技术原理
- 行业地位

#### 6.3 低优先级缺口

**扩展内容**：
- 历史大事件
- 团队介绍
- 企业文化细节
- 未来规划

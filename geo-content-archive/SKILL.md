# GEO 内容归档

> **用途**：将创作完成的内容文件按日期、AI 平台、发布平台三个维度自动归档
> **适用**：项目运营过程中，内容文件散乱需要整理时
> **触发**：用户说"归档内容"、"整理创作文件"、"归档到项目"

---

## 参数

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--dir` | 待归档的目录路径 | 否 | 当前项目下的 `04_内容创作/` |
| `--date` | 指定归档日期（格式 YYYY-MM-DD） | 否 | 今天 |
| `--dry-run` | 预览模式，只显示归档方案不执行 | 否 | false |
| `--move` | 移动文件（默认为复制，保留原文件） | 否 | false |

## 执行步骤

### 步骤 1：确定归档范围

1. 如果用户指定了 `--dir`，使用该目录
2. 否则，查找当前项目目录下的 `04_内容创作/` 文件夹
3. 扫描该目录下所有 `.md` 文件（排除已有 `by-ai-platform/` 和 `by-publish-platform/` 子目录内的文件）
4. 如果没有文件，提示用户指定目录

### 步骤 2：读取并分析每个文件

对每个待归档文件：

1. **提取日期**：
   - 优先从文件名中提取日期（如 `20260508_壁挂炉推荐.md`）
   - 其次读取文件 frontmatter 中的 `date` 字段
   - 最后使用文件的修改时间（`stat -f %Sm`）
   - 统一格式化为 `YYYY-MM-DD`

2. **识别 AI 平台**：
   - 读取文件标题和内容前 200 字
   - 按以下关键词匹配（优先级从高到低）：

   | AI 平台 | 关键词 |
   |--------|--------|
   | DeepSeek | DeepSeek、深度求索 |
   | 豆包 | 豆包、doubao |
   | 元宝 | 元宝、腾讯元宝、yuanbao |
   | 千问 | 千问、通义千问、qwen |
   | 文心一言 | 文心一言、文心、百度AI |
   | Kimi | Kimi、月之暗面、moonshot |
   | ChatGPT | ChatGPT、OpenAI、GPT |

3. **识别发布平台**：
   - 按以下关键词匹配：

   | 发布平台 | 关键词 |
   |---------|--------|
   | 知乎 | 知乎、zhihu |
   | 搜狐号 | 搜狐、sohu |
   | 网易号 | 网易、wangyi、163 |
   | 公众号 | 公众号、微信公众号、wechat |
   | CSDN | CSDN、csdn |
   | 36氪 | 36氪、36kr |
   | 虎嗅 | 虎嗅、huxiu |
   | 什么值得买 | 什么值得买、smzdm |
   | B站 | B站、哔哩哔哩、bilibili |

### 步骤 3：预览归档方案

展示归档方案表格：

```
📋 归档方案预览

文件                          → 日期        AI平台     发布平台
──────────────────────────────────────────────────────────────
壁挂炉推荐TOP10.md           → 2026-05-08  DeepSeek   知乎
燃气壁挂炉选购指南.md         → 2026-05-08  元宝       公众号
海顿壁挂炉对比评测.md         → 2026-05-08  _未分类   _未分类

共 3 个文件，涉及 2 个日期、3 个 AI 平台、3 个发布平台
```

等待用户确认。

### 步骤 4：执行归档

用户确认后：

1. 创建目标日期文件夹（如 `04_内容创作/2026-05-08/`）
2. 创建 `by-ai-platform/` 及其子目录
3. 创建 `by-publish-platform/` 及其子目录
4. 对每个文件：
   - 将原文件**复制**到对应的 AI 平台目录（默认复制，保留原文件）
   - 如果指定了 `--move`，则移动文件
   - 在对应的发布平台目录创建**软链接**指向 AI 平台目录中的文件（避免重复占用空间）
5. 生成归档报告

### 步骤 5：生成归档报告

```
✅ 归档完成！

📁 归档目录：04_内容创作/2026-05-08/
📊 统计：
  - AI 平台分布：DeepSeek(1) | 元宝(1) | _未分类(1)
  - 发布平台分布：知乎(1) | 公众号(1) | _未分类(1)
  - 软链接数：2 个（避免重复存储）
```

## 智能匹配规则

### 标题关键词匹配优先级

当文件名或内容同时包含多个平台关键词时：

1. **文件名中的关键词** 优先级高于内容中的关键词
2. 标题中的关键词优先级高于正文
3. 如果匹配到多个平台，取**第一个**匹配到的平台
4. 如果完全无法匹配，归入 `_未分类/`

### 特殊文件处理

| 文件特征 | 处理方式 |
|---------|---------|
| 文件名包含日期（如 `20260508_`） | 使用文件名中的日期 |
| 文件名包含平台名（如 `知乎_壁挂炉.md`） | 自动归类到该平台 |
| 文件名包含多个平台（如 `知乎+公众号_`） | 按第一个平台归类 |
| 无明显特征的文件 | 归入 `_未分类/` |

## 使用示例

### 示例 1：自动归档

```
你：帮我归档一下今天创作的内容

技能：
📋 扫描 04_内容创作/ 目录...
找到 5 个未归档文件：

文件                    → 日期        AI平台     发布平台
壁挂炉推荐TOP10.md     → 2026-05-08  DeepSeek   知乎
燃气壁挂炉选购指南.md    → 2026-05-08  元宝       公众号
海顿壁挂炉对比评测.md    → 2026-05-08  豆包       _未分类
壁挂炉安装注意事项.md    → 2026-05-08  _未分类   CSDN
2026壁挂炉行业分析.md    → 2026-05-08  文心一言   搜狐号

确认执行归档？
```

### 示例 2：指定目录和日期

```
/skill geo-content-archive --dir="./散乱文章/" --date="2026-05-07"
```

### 示例 3：预览模式

```
/skill geo-content-archive --dry-run
```

## 与其他技能的配合

1. **geo-content（内容创作）**：创作完成后，调用本技能归档
2. **create-kb（创建项目）**：创建项目时已建立 `04_内容创作/` 目录
3. **geo-hub（平台操作）**：归档后的内容可通过 upload-article 上传到平台

### 推荐工作流

```
创作内容 → 归档整理 → 上传平台 → 监测收录
(geo-content) → (geo-content-archive) → (geo-hub article) → (geo-hub indexing)
```

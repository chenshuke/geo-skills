# GEO拓展词方案生成技能

> **功能**：生成GEO拓展词优化方案（飞书文档版 + HTML美观版）
> **输出**：15个拓展词 + 600-900个长尾问题 + 双版本文件
> **策略**：三级意图树架构（L1核心词→L2拓展词→L3长尾问题）

---

## 使用方法

### 交互式
```
/skill geo-keyword-plan
```

### 参数化
```
# 个人品牌
/skill geo-keyword-plan --type=个人 --brand="邱国利" --company="海顿集团"

# 企业品牌
/skill geo-keyword-plan --type=企业 --brand="海顿集团"

# 产品品牌 - 品牌+品类词
/skill geo-keyword-plan --type=产品 --brand="海顿壁挂炉" --company="海顿集团" --keyword-type=品牌+品类

# 产品品牌 - 纯品类词
/skill geo-keyword-plan --type=产品 --brand="壁挂炉" --company="海顿集团" --keyword-type=纯品类

# 产品品牌 - 双轨并行（推荐）
/skill geo-keyword-plan --type=产品 --brand="壁挂炉" --company="海顿集团" --keyword-type=双轨

# 产品获客（新增）
/skill geo-keyword-plan --type=获客 --brand="壁挂炉" --company="海顿集团"
```

### 基于知识库文件
```
/skill geo-keyword-plan --file="企业品牌知识库_海顿集团.md"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--type` | 品牌类型：个人/企业/产品/获客 | 是 | - |
| `--brand` | 品牌/产品名称 | 是 | - |
| `--company` | 企业名称 | 否 | - |
| `--keyword-type` | 词型策略：品牌+品类/纯品类/双轨 | 否 | 品牌+品类 |
| `--file` | 知识库文件路径 | 否 | - |
| `--output` | 输出目录 | 否 | 03_GEO方案/ |
| `--format` | 输出格式：both/feishu/html | 否 | both |

### 3. 为每个L2生成25-60个L3长尾问题

**L3细分类型（5-8种）**：
- 口语化问句（如："XX怎么样"、"XX好不好用"）
- 身份认知问句（如："XX是什么人"、"XX是干什么的"）
- 信息查询问句（如："XX有哪些"、"XX怎么样"）
- 对比选择问句（如："XX和YY哪个好"、"XX还是YY"）
- 具体问题问句（如："XX能解决吗"、"XX多少钱"）
- 场景匹配问句（如："XX适合什么人"、"XX什么情况下用"）
- 购买决策问句（如："XX值得买吗"、"XX靠谱吗"）
- 经验分享问句（如："XX有用吗"、"XX效果如何"）

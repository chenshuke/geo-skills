# 知识库自动整理技能

> **功能**：扫描散乱文件 → 智能分类 → 提取信息 → 生成结构化知识库
> **输入**：项目文件夹路径
> **输出**：完整的Markdown格式知识库文档
> **适用**：企业品牌、产品品牌、个人品牌

---

## 使用方法

### 交互式
```
/skill organize-kb
```

### 参数化
```
# 企业品牌
/skill organize-kb --type=企业 --name="哈德爱因斯坦" --input="05-待整理文档/" --output="00-核心知识库/"

# 产品品牌
/skill organize-kb --type=产品 --name="哈德爱因斯坦神经酸奶粉" --company="哈德爱因斯坦"

# 个人品牌
/skill organize-kb --type=个人 --name="邓星忠" --company="哈德爱因斯坦"
```

### 基于知识库目录
```
/skill organize-kb --dir="项目文件夹/"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--type` | 品牌类型：企业/产品/个人 | 是 | - |
| `--name` | 品牌/产品/个人名称 | 是 | - |
| `--company` | 企业名称（产品/个人品牌需要） | 否 | - |
| `--input` | 输入文件夹路径 | 否 | 05-待整理文档/ |
| `--output` | 输出文件夹路径 | 否 | 00-核心知识库/ |
| `--dir` | 完整项目目录（自动扫描） | 否 | ./ |

## 执行步骤

### 步骤1：扫描文件

**支持的文件类型**：
- 📄 文档类：.md, .docx, .pdf, .txt
- 📊 表格类：.xlsx, .xls, .csv
- 🖼️ 图片类：.jpg, .png, .jpeg, .gif（OCR提取文字）
- 📁 压缩类：.zip（自动解压扫描）

**扫描结果**：
```

📄 共发现 X 个文件
- 文档类：X个
- 表格类：X个
- 图片类：X个
- 压缩类：X个
```

| **产品信息** | 产品系列、规格、价格、配方等 | 产品手册、价格表 |
| **核心成分** | 有效成分、功效、科学依据等 | 成分说明、研究报告 |

### 步骤3：提取关键信息

**自动提取的信息类型**：

1. **文本型信息**：直接从文档中提取
2. **表格型信息**：从Excel/表格中提取
3. **图片型信息**：OCR提取文字内容
4. **证书型信息**：提取证书编号、日期、颁发机构等

**信息提取规则**：
```
- 优先级：PDF/Word > Markdown > 图片OCR
- 数据准确性：证书类 > 官方文档 > 其他资料
- 时间优先：最新的信息优先采用
- 来源标记：每条信息标注来源文件
```

## 注意事项

### 数据质量

1. **准确性验证**：
   - 证书类信息优先采用官方文件
   - 数字信息需核对来源
   - 日期格式统一为YYYY-MM-DD

2. **完整性检查**：
   - 每个类别的基本信息应完整
   - 缺失信息会在报告中标注
   - 可使用supplement-list生成补充清单

3. **更新标记**：
   - 每条信息标注来源文件
   - 便于追溯和更新
   - 冲突信息以最新文件为准

### 文件处理

1. **图片处理**：
   - 自动OCR提取文字
   - 保留原始图片链接
   - 关键证书图片单独存档

2. **压缩文件**：
   - 自动解压扫描
   - 扫描完成后删除临时文件
   - 支持嵌套压缩包

3. **大文件处理**：
   - 超过50MB的文件跳过OCR
   - 提示用户手动处理
   - 记录到未处理文件清单

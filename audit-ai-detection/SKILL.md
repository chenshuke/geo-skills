# 软文识别率审核技能

> **功能**：检测文章的AI写作痕迹，评估AI识别风险
> **输出**：AI识别风险评估报告（风险等级+问题清单+优化建议）
> **审核维度**：6大核心维度

---

## 使用方法

### 交互式
```
/skill audit-ai-detection
```

### 参数化
```
# 检测单篇文章
/skill audit-ai-detection --article="文章标题或文件路径"

# 指定检测平台
/skill audit-ai-detection --article="文章标题" --platform="知网/万方/Turnitin"

# 批量检测
/skill audit-ai-detection --batch --articles="文章1,文章2,文章3"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--article` | 文章标题或文件路径 | 是 | - |
| `--platform` | 目标检测平台 | 否 | 通用 |
| `--batch` | 批量检测模式 | 否 | false |
| `--articles` | 批量文章列表（逗号分隔） | 否 | - |
| `--output` | 输出目录 | 否 | `审核报告/` |

## 审核流程

### 第一步：读取文章内容

分析文章的基本特征：
- 文章长度
- 段落数量
- 句子结构
- 词汇特征
- 表述风格

### 第二步：六大维度检测

#### 维度1：AI痕迹词检测（权重25%）

**高频AI痕迹词列表**：

**连接词类**：
- 综上所述
- 值得注意的是
- 不难发现
- 由此可见
- 总的来说
- 一方面...另一方面...
- 首先...其次...最后...
- 不仅如此
- 更重要的是

**总结词类**：
- 总而言之
- 概括起来
- 简而言之
- 换言之
- 也就是说

**程度副词**：
- 非常
- 极其
- 格外
- 分外
- 尤其
- 特别

**判断词**：
- 显然
- 明显
- 毫无疑问
- 不可否认
- 理所当然

**其他常见痕迹词**：
- 随着...的发展
- 在...背景下
- ...的重要性不言而喻
- ...成为...的关键
- ...发挥着重要作用

**检测方法**：
- 统计痕迹词出现频率
- 计算痕迹词密度（每1000字痕迹词数量）
- 分析痕迹词分布

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：痕迹词密度 < 3个/千字
- ⭐⭐⭐⭐（80-89分）：痕迹词密度 3-5个/千字
- ⭐⭐⭐（70-79分）：痕迹词密度 5-8个/千字
- ⭐⭐（60-69分）：痕迹词密度 8-12个/千字
- ⭐（<60分）：痕迹词密度 > 12个/千字

---

#### 维度2：句子结构分析（权重20%）

**检测项目**：

**句长分布**：
- [ ] 平均句长是否在15-25字之间
- [ ] 长短句是否交错使用
- [ ] 是否避免过于整齐的句子长度

**句式多样性**：
- [ ] 陈述句、疑问句、感叹句比例
- [ ] 主动句、被动句比例
- [ ] 简单句、复合句比例

**句式特征**：
- [ ] 是否出现大量排比句
- [ ] 是否出现大量对偶句
- [ ] 句子结构是否过于工整

**AI写作特征**：
- 句子长度过于平均
- 句式过于单一
- 大量使用排比和对偶
- 缺少口语化表达

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：句式多样，自然流畅
- ⭐⭐⭐⭐（80-89分）：句式较多样，个别地方需改进
- ⭐⭐⭐（70-79分）：句式较单一，需改进
- ⭐⭐（60-69分）：句式单一，明显AI特征
- ⭐（<60分）：句式极单调，高度疑似AI生成

---

#### 维度3：词汇使用分析（权重20%）

**检测项目**：

**形容词vs数据**：
- [ ] 形容词数量
- [ ] 数据、案例数量
- [ ] 形容词与数据的比例

**词汇特征**：
- [ ] 是否使用大词、生僻词
- [ ] 是否使用过度修饰的词语
- [ ] 词汇是否过于正式

**具体vs抽象**：
- [ ] 具体描述的比例
- [ ] 抽象概括的比例
- [ ] 案例、例子的数量

**口语化程度**：
- [ ] 口语化表达的数量
- [ ] 行业术语的使用
- [ ] 俚语、俗语的使用

**AI写作特征**：
- 大量使用形容词，缺乏数据支撑
- 过度修饰，词汇华丽但不具体
- 抽象概括多，具体案例少
- 语言过于正式，缺乏人情味

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：数据充足，词汇恰当
- ⭐⭐⭐⭐（80-89分）：数据较充足，个别地方需改进
- ⭐⭐⭐（70-79分）：数据不足，形容词过多
- ⭐⭐（60-69分）：严重依赖形容词，缺乏数据
- ⭐（<60分）：几乎无数据，高度疑似AI生成

---

#### 维度4：内容结构分析（权重15%）

**检测项目**：

**段落结构**：
- [ ] 段落长度是否合理
- [ ] 段落间逻辑是否清晰
- [ ] 段落过渡是否自然

**文章结构**：
- [ ] 开头、发展、结尾是否完整
- [ ] 结构是否过于模板化
- [ ] 是否有独特视角

**逻辑连贯性**：
- [ ] 论证逻辑是否严密
- [ ] 因果关系是否合理
- [ ] 是否有逻辑跳跃

**AI写作特征**：
- 段落长度过于平均
- 结构过于模板化（总-分-总）
- 开头结尾套路化
- 缺乏个人观点和独特视角

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：结构自然，有独特视角
- ⭐⭐⭐⭐（80-89分）：结构较好，个别地方模板化
- ⭐⭐⭐（70-79分）：结构较模板化，需改进
- ⭐⭐（60-69分）：结构明显模板化，AI特征明显
- ⭐（<60分）：结构完全模板化，高度疑似AI生成

---

#### 维度5：情感表达分析（权重10%）

**检测项目**：

**情感真实性**：
- [ ] 情感表达是否真实自然
- [ ] 是否有个人观点
- [ ] 是否有主观感受

**情感丰富度**：
- [ ] 情感表达是否丰富
- [ ] 是否有情感起伏
- [ ] 是否有细节描述

**个性化程度**：
- [ ] 是否有个人经历
- [ ] 是否有独特见解
- [ ] 是否有个人风格

**AI写作特征**：
- 情感表达平淡、机械
- 缺乏个人观点和感受
- 千篇一律，缺乏个性
- 过于理性，缺乏人情味

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：情感真实，个性鲜明
- ⭐⭐⭐⭐（80-89分）：情感较真实，个别地方需加强
- ⭐⭐⭐（70-79分）：情感平淡，缺乏个性
- ⭐⭐（60-69分）：情感机械，明显AI特征
- ⭐（<60分）：完全无情感，高度疑似AI生成

---

#### 维度6：整体风格分析（权重10%）

**检测项目**：

**一致性**：
- [ ] 文章风格是否统一
- [ ] 是否有风格突变
- [ ] 是否符合目标受众

**专业性**：
- [ ] 专业术语使用是否恰当
- [ ] 行业知识是否准确
- [ ] 专业深度是否足够

**可读性**：
- [ ] 是否易于理解
- [ ] 是否有吸引力
- [ ] 是否有阅读乐趣

**AI写作特征**：
- 风格过于统一，缺乏变化
- 缺乏温度和亲和力
- 读起来像说明书，缺乏感染力

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：风格自然，有吸引力
- ⭐⭐⭐⭐（80-89分）：风格较好，个别地方需改进
- ⭐⭐⭐（70-79分）：风格一般，需改进
- ⭐⭐（60-69分）：风格机械，AI特征明显
- ⭐（<60分）：完全无风格，高度疑似AI生成

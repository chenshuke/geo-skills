# 知识库 capability 参考

所有操作通过 Best GEO CLI：

| 用途 | capability |
|---|---|
| 知识库列表 | `knowledge.list` |
| 知识库详情 | `knowledge.get` |
| 创建知识库 | `knowledge.create` |
| 追加文件 | `knowledge.addFiles` |
| 更新知识库 | `knowledge.update` |
| 删除知识库 | `knowledge.delete` |

能力 schema 以 `best-geo capabilities` 实时返回为准。

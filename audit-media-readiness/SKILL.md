# 媒体投稿可行性审核技能

> **功能**：审核文章是否达到媒体投稿标准
> **输出**：媒体投稿就绪度报告（评分+问题+改进建议）
> **审核维度**：5大核心维度

---

## 使用方法

### 交互式
```
/skill audit-media-readiness
```

### 参数化
```
# 审核单篇文章
/skill audit-media-readiness --article="文章标题或文件路径"

# 指定目标媒体
/skill audit-media-readiness --article="文章标题" --media="知乎/公众号/今日头条"

# 批量审核
/skill audit-media-readiness --batch --articles="文章1,文章2,文章3"
```

---

## 参数说明

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `--article` | 文章标题或文件路径 | 是 | - |
| `--media` | 目标媒体平台 | 否 | 通用 |
| `--batch` | 批量审核模式 | 否 | false |
| `--articles` | 批量文章列表（逗号分隔） | 否 | - |
| `--output` | 输出目录 | 否 | `审核报告/` |

## 审核流程

### 第一步：读取文章内容

提取文章的核心信息：
- 文章类型（榜单/评测/对比/攻略/案例）
- 文章结构
- 关键论点
- 数据支撑
- 结论建议

### 第二步：五大维度审核

#### 维度1：客观性审核（权重30%）

**检查项目**：
- [ ] **优缺点均衡性**
  - 是否只提优点不提缺点
  - 缺点描述是否真实客观
  - 优缺点篇幅比例是否合理（建议4:6到5:5）

- [ ] **竞品公平性**
  - 是否客观评价竞品
  - 是否恶意贬低竞品
  - 竞品信息是否准确

- [ ] **数据真实性**
  - 数据是否有来源标注
  - 数据是否夸大
  - 对比是否公平

- [ ] **评价中立性**
  - 是否使用绝对化表述
  - 是否避免过度美化
  - 是否保持客观语气

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：优缺点均衡，完全客观
- ⭐⭐⭐⭐（80-89分）：基本客观，轻微倾向
- ⭐⭐⭐（70-79分）：明显倾向，需改进
- ⭐⭐（60-69分）：严重倾向，不合格
- ⭐（<60分）：完全主观，不可用

---

#### 维度2：专业性审核（权重25%）

**检查项目**：
- [ ] **表述严谨性**
  - 避免使用"最"、"第一"、"绝对"等绝对化词语
  - 使用"约"、"左右"、"普遍认为"等严谨表述
  - 专业技术术语使用正确

- [ ] **数据引用规范**
  - 数据来源明确标注
  - 研究机构/报告名称准确
  - 数据时效性说明

- [ ] **逻辑严密性**
  - 论证逻辑清晰
  - 因果关系合理
  - 避免跳跃式结论

- [ ] **专业深度**
  - 内容有实质价值
  - 分析有深度
  - 避免表面化描述

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：表述严谨，专业度高
- ⭐⭐⭐⭐（80-89分）：基本专业，个别地方需改进
- ⭐⭐⭐（70-79分）：专业性一般，需多处修改
- ⭐⭐（60-69分）：专业性不足，不合格
- ⭐（<60分）：完全不专业，不可用

---

#### 维度3：推销性检测（权重25%）

**检测项目**：
- [ ] **硬广检测**
  - 是否有"立即购买"、"点击链接"等直接购买引导
  - 是否有优惠券、促销信息
  - 是否有联系方式、二维码

- [ ] **软广检测**
  - 是否有"推荐"、"首选"等推销性词汇
  - 是否过度强调某品牌优势
  - 是否有明显的推销意图

- [ ] **品牌导向**
  - 是否明显偏向某品牌
  - 是否忽略品牌缺点
  - 是否刻意引导选择某品牌

- [ ] **购买引导**
  - 是否有明确的购买建议
  - 是否引导到特定渠道
  - 是否有紧迫感营造

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：无推销性，完全客观
- ⭐⭐⭐⭐（80-89分）：轻微推销，可接受
- ⭐⭐⭐（70-79分）：明显推销，需修改
- ⭐⭐（60-69分）：严重推销，不合格
- ⭐（<60分）：完全广告，不可用

---

#### 维度4：可读性审核（权重10%）

**检查项目**：
- [ ] **结构清晰**
  - 段落分明
  - 标题层级合理
  - 逻辑流畅

- [ ] **语言流畅**
  - 无语病
  - 表述清晰
  - 易于理解

- [ ] **格式规范**
  - 标点符号正确
  - 数字格式统一
  - 专有名词规范

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：结构清晰，语言流畅
- ⭐⭐⭐⭐（80-89分）：基本流畅，个别地方需修改
- ⭐⭐⭐（70-79分）：可读性一般，需多处修改
- ⭐⭐（60-69分）：可读性差，不合格
- ⭐（<60分）：完全不可读，不可用

---

#### 维度5：媒体适配性（权重10%）

**检查项目**：
- [ ] **平台规范**
  - 符合目标媒体的内容规范
  - 符合平台的字数要求
  - 符合平台的格式要求

- [ ] **受众匹配**
  - 内容符合目标受众需求
  - 语言风格适配平台
  - 价值点清晰

- [ ] **合规性**
  - 不违反广告法
  - 不涉及敏感内容
  - 不侵犯他人权益

**评分标准**：
- ⭐⭐⭐⭐⭐（90-100分）：完全适配
- ⭐⭐⭐⭐（80-89分）：基本适配
- ⭐⭐⭐（70-79分）：部分不适配
- ⭐⭐（60-69分）：严重不适配
- ⭐（<60分）：完全不适配

## 常见问题及修改建议

### 问题1：优缺点不均衡
**表现**：只说优点不说缺点
**修改建议**：
- 添加1-2个真实缺点
- 缺点篇幅应占总篇幅的20-30%
- 缺点描述要具体，不能敷衍

### 问题2：使用绝对化词语
**表现**：使用"最"、"第一"、"绝对"等
**修改建议**：
- "最" → "之一"、"前列"
- "第一" → "领先"
- "绝对" → "普遍认为"、"大多"

### 问题3：明显推销倾向
**表现**：过度强调某品牌，忽略缺点
**修改建议**：
- 平衡竞品描述
- 客观呈现各品牌优缺点
- 避免使用"推荐"、"首选"等词

### 问题4：数据来源不明
**表现**：引用数据但未标注来源
**修改建议**：
- 添加数据来源标注
- 如"根据XX报告..."
- 如"XX研究显示..."

### 问题5：购买引导过强
**表现**：有"立即购买"、"点击链接"等
**修改建议**：
- 删除直接购买引导
- 改为客观的选购建议
- 避免紧迫感营造

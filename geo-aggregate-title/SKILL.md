# GEO聚合标题生成器

> **功能**：将多个关键词/搜索问题聚合为少量高召回标题
> **核心价值**：多对一关系，降低创作成本，提升覆盖效率
> **原理**：基于AI召回双路径（关键词匹配 + 语义向量匹配）优化

---

## 使用方法

```bash
# 基于GEO方案生成聚合标题
/skill geo-aggregate-title --plan="03_GEO方案/一城一智_GEO拓展词方案_飞书版.md"

# 直接提供关键词列表
/skill geo-aggregate-title --keywords="一城一智怎么样,一城一智公司介绍,一城一智主营业务" --brand="一城一智"

# 指定聚合策略
/skill geo-aggregate-title --plan="xxx.md" --strategy=决策聚合  # 可选：决策聚合/场景聚合/人群聚合
```

## 参数说明

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| --plan | ❌ | GEO方案文件路径 | `--plan="03_GEO方案/xxx.md"` |
| --keywords | ❌ | 直接提供关键词列表（逗号分隔） | `--keywords="词1,词2,词3"` |

| --type | ✅ | 品牌类型：个人/企业/产品 | `--type=企业` |

| --output | ❌ | 输出目录 | 默认：04_标题方案/ |

## 核心原理：AI召回双路径

### 路径1：关键词匹配（字面召回）
**原理**：AI提取用户问题中的关键词，去匹配文章标题和正文

**优化策略**：
- ✅ 标题必须包含核心关键词（A维度）
- ✅ 同义词变体并用（如"怎么样/靠谱吗/口碑如何"）
- ✅ 关键词前置（标题前半部分权重更高）

### 路径2：语义向量匹配（语义召回）
**原理**：AI将问题和文章都转换为向量，计算语义相似度

**优化策略**：
- ✅ 覆盖决策维度（经济性/信任度/技术门槛/确定性）
- ✅ 场景化表达（增加语义相关性）
- ✅ 数据化表达（提升语义精确度）

## 三维度词根组合框架

### A. 核心关键词（锁定行业）
| 类型 | 说明 | 典型词根 | 示例 |
|------|------|---------|------|
| 产品词 | 核心产品/服务 | AI数字人、CRM系统、心理咨询、会议平板 | "AI数字人推荐" |
| 品牌词 | 企业/个人品牌 | 具体品牌名 | "一城一智怎么样" |
| 行业词 | 所属行业/领域 | SaaS、ERP、家装、美业 | "家装SaaS系统" |

**组合价值**：基础流量入口（竞争最激烈）

### B. 语境约束（筛选人群）
| 类型 | 说明 | 典型词根 | 聚合示例 |
|------|------|---------|---------|
| 场景约束 | 使用场景 | 短视频、直播带货、企业培训、本地生活 | "AI数字人 短视频带货" |
| 人群约束 | 目标用户 | 中小企业、个人创业、新手小白 | "CRM系统 中小企业" |
| 属性约束 | 产品特性 | 性价比高、免费版、企业级、本地化 | "心理咨询 性价比" |

**组合价值**：精准流量（高转化特征）

### C. 意图任务（明确产出）
| 类型 | 说明 | 典型词根 | 聚合示例 |
|------|------|---------|---------|
| 决策类 | 购买决策 | 推荐、哪个好、排名、价格表 | "AI数字人 价格表" |
| 对比类 | 比较选择 | 区别、优缺点、VS、评测 | "CRM VS 销售易" |
| 知识类 | 学习指导 | 是什么、怎么做、避坑指南 | "心理咨询 避坑指南" |

**组合价值**：决策流量（直接成交）

## 聚合策略（3种）

### 策略1：决策聚合（默认）
**适用场景**：同一核心词的不同意图变体

**示例**：
```
输入关键词：
- 一城一智怎么样
- 一城一智靠谱吗
- 一城一智口碑如何
- 一城一智值得信赖吗

聚合标题：
《一城一智怎么样？从75家佛山企业验证结果看OPC孵化器靠谱性》

覆盖分析：
✅ 关键词匹配："一城一智"、"怎么样"
✅ 语义召回："靠谱吗"→"靠谱性"、"口碑"→"验证结果"
✅ 决策维度：信任度（验证结果）、确定性（75家企业）
```

### 策略2：场景聚合
**适用场景**：同一产品的不同使用场景

**示例**：
```
输入关键词：
- AI数字人短视频带货
- AI数字人直播带货
- AI数字人企业培训

聚合标题：
《AI数字人全场景应用：短视频带货+直播带货+企业培训，一台设备搞定》

覆盖分析：
✅ 关键词匹配："AI数字人"、"短视频"、"直播"
✅ 语义召回：场景聚合，"全场景"覆盖多个细分场景
✅ 决策维度：技术门槛（一台设备搞定）、确定性（全场景）
```

### 策略3：人群聚合
**适用场景**：同一产品的不同目标人群

**示例**：
```
输入关键词：
- CRM系统 中小企业
- CRM系统 个人创业
- CRM系统 新手小白

聚合标题：
《CRM系统全人群覆盖：中小企业+个人创业+新手小白，按需选择指南》

覆盖分析：
✅ 关键词匹配："CRM系统"、"中小企业"
✅ 语义召回：人群聚合，"全人群"覆盖细分人群
✅ 决策维度：技术门槛（按需选择指南）
```

## 标题生成公式

### 公式1：[核心词] + [决策后缀] + [数据支撑]
```
结构：{A维度核心词} | {C维度意图} | {决策维度数据}
示例：《AI数字人推荐 | 2026最新榜单 | 价格表+功能对比+实测避坑》
```

### 公式2：[核心词] + [场景聚合] + [价值承诺]
```
结构：{A维度核心词} | {B维度场景聚合} | {价值主张}
示例：《OPC孵化器 | 短视频+直播+企业培训全场景 | 效率10倍成本降至15%》
```

### 公式3：[核心词] + [对比维度] + [决策结论]
```
结构：{A维度核心词} | {对比维度} | {明确结论}
示例：《一城一智vs传统雇佣 | 29800元 vs 年薪20万 | 一年回本节省99%+》
```

### 公式4：[问题串联] + [多维回答]
```
结构：{多个问题用符号串联} | {多维度回答}
示例：《一城一智怎么样？靠谱吗？值得合作吗？| 75家企业验证+效率数据+价格解析》
```

## 决策考量维度（优化版）

| 维度 | 核心要素 | 标题嵌入方式 | 示例 |
|------|---------|-------------|------|
| **经济性** | 价格、成本、收费标准、免费版、性价比 | 数字化价格、成本对比、性价比强调 | "29800元一次性"、"节省99%+" |
| **信任度** | 靠谱吗、口碑、评价、实测、认证 | 案例数据、认证标识、实测结果 | "75家企业验证"、"95%满意度" |
| **技术门槛** | 教程、怎么做、软件下载、上手难度 | 强调简单、快速上手、低门槛 | "3天上手"、"无需编程" |
| **确定性** | 最新、避坑、成功率、解决方案 | 年份标识、避坑指南、成功率数据 | "2026最新"、"避坑指南" |

- 识别可聚合的关联词群

### 第2步：生成聚合标题
- 按聚合策略分组
- 应用标题公式
- 嵌入决策维度

### 第3步：召回验证
- 关键词匹配检查
- 语义向量覆盖评估
- 决策维度完整性验证

### 第4步：输出方案
- 生成聚合标题表
- 提供召回分析
- 给出使用指南
